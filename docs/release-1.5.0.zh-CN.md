# EdgeTerm 1.5.0

本分支相对上一个公开版本 **1.4.0** 的更新，面向 Windows x64，继续手动下载和安装。已有安装版沿用应用标识 `com.edgeterm.desktop`、配置目录和凭据存储，本版本没有数据格式迁移。

## 终端与标签

- 隐藏终端继续接收和解析输出，但不再对不可见区域反复执行视口着色和行号同步；全屏程序遮住普通历史时，历史着色等返回后再继续。
- 多个终端之间快速切换时，被 GPU 渲染池挤出的标签先显示普通渲染，停留后再恢复 GPU；可见字符的字体宽度合并测量，并保留选区与终端同步输出行为。
- 简化后台标签活动动画，并在标签列表中显示连接状态和需要查看的会话。AI 会话的安静间隔只是提醒用户查看，不能证明工具已经完成。
- 本机合成会话的前后测试与限制见[终端性能记录](terminal-performance.zh-CN.md)。该结果不是实际用户会话的延迟保证。

## 文件、传输和命令

- 文件栏列超出可用宽度时提供切换按钮，可在名称和更多列之间移动；大字号下文件名保留可读空间。
- 传输队列的路径和失败项可打开可选择的只读详情，关闭后焦点返回原按钮。
- Sender 中保存的命令新增可见的选项按钮；键盘焦点也能显示命令预览。

## 工作区和工作台

- 空工作区重新组织创建会话和面板入口，狭窄空间可滚动，键盘焦点保持可见。
- 窄工作台调整标题、导航、路径和冲突提示的布局；运行控制台可以收起，多个主机的名称也更容易区分。
- 主机网络速率采样为零时显示 `0 B/s`，无数据时继续显示不可用；状态栏资源摘要在不同宽度下保持在按钮范围内。

## 安装与数据保留

安装版用户下载 `EdgeTerm_1.5.0_x64-setup.exe`，退出应用后安装到原位置，无需先卸载。便携版使用程序旁的 `data` 文件夹；升级便携版时保留已有 `data`，不要用空目录覆盖它。便携模式的密码只在当前进程会话内保存。

本分支不后台检查或自动安装更新；应用中的“下载与更新…”打开本分支发布页。可用发布页的 `SHA256SUMS.txt` 核对下载的附件。安装器与程序未进行 Windows 数字签名；校验和用于核对文件完整性，不能代替发布者签名验证。独立诊断包用于从应用外部收集窗口无响应的证据，不会自动上传。

## 验证边界

Windows x64 本地检查：106 个前端单元测试文件 / 909 项、31 个浏览器测试文件 / 152 项、449 项 Rust 测试通过；另有 27 项 Rust 测试按配置跳过。TypeScript、Biome 格式、lint、Rust 格式和 Rust/前端绑定一致性检查通过；lint 保留生成绑定中的两条既有 `any` 警告。

浏览器回归使用模拟 IPC；桌面回归覆盖 Windows WebView2、ConPTY、合成输出以及不调用模型的合成 OpenCode 会话。这些检查不能替代真实 SSH/SFTP 服务器、活跃模型流式输出、已有用户数据的安装升级、其他显卡组合或 macOS/Linux 桌面环境的验收。具体构建来源、附件校验和与验证结果见[发布索引](releases.zh-CN.md)。
