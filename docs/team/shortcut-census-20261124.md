# 给快捷键表加一次普查（2026-11-24 第 105 轮）

`shortcuts.ts` 里有三张必须互相对齐的表：命令清单、名字、说明；外加两份平台默认值。此前只有一个测试断言「解析与匹配」的正确性，**没有任何东西保证这五份数据对得上**。

## 一、四条不变量

| 断言 | 防的是什么 |
| --- | --- |
| 每个命令都有英文名与提示，且不是原始 key | 新增命令忘记补文案，界面显示 `sc.foo.label` |
| 命令不重复 | 设置页出现两行同一个动作 |
| 同一平台内没有两个命令抢同一个和弦；和弦标签非空 | 后注册的永远抢不到键／帮助里显示空白 |
| 两份平台表对同一命令「有默认值」保持一致 | 只在 mac 上能用的动作被当成跨平台 |

## 四、边界

普查只看**默认值**，不看用户自定义的组合：用户当然可以自己撞车，设置对话框通过 `chordProblem` 提示并让用户决定。这条区别写在测试注释里，免得后人以为普查漏了。
