## 确认无缺陷

- 串口列表不会过期：list_serial_ports 与对话框都不缓存，有可用的刷新按钮，失败提示也指向它。
- Telnet 协商不会挂住连接：15 秒超时；Q 方法符合 RFC 1143，每条测试都证明不会回复成环；登录窗口 60 秒与文案一致；连接后的尺寸重发修正了硬编码的 80x24 NAWS。
- FTP 不会把半个文件当成功：下载校验 offset == source.size，上传复查 SIZE；任一文件失败整个任务失败；Options::validate 强制 files >= 1，工作池不可能为空；部分提交的恢复有哈希校验。
- 被动模式可见：后端始终被动，两语言副标题都写明 passive mode。
- 文案里的波特率与代码一致：115200 在三处相同；Telnet 的 23 与协商文案匹配；两语言键集合完全相同（各 1519 键）。
- 断开不会占用端口：close_session 发送 Close 并 join 串口所属线程，端口在每条退出路径上被 drop（有测试证明）。

边界：静态读源码，未在真实串口设备或 FTP 服务器上点检。
