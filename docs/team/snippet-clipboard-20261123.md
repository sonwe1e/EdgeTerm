# 常用命令通过剪贴板搬家（2026-11-23 第 49 轮）

保存下来的命令目前只活在这台机器上。想换机、想给同事一份、想批量整理，都没有出口。本轮给它们一个可搬运的形式：**一小段 JSON，走剪贴板**。

## 一、行为

| 动作 | 结果 |
| --- | --- |
| 复制全部 | 把整份列表以可读 JSON 写进剪贴板，状态提示「已复制 N 条常用命令」；列表为空时按钮禁用 |
| 从剪贴板导入 | 读取剪贴板，校验后按名称合并（同名覆盖命令）；成功提示导入条数与跳过条数 |
| 剪贴板不是 JSON / 不是本应用的包 / 包为空 | 分别说明原因，一条也不导入 |
| 导入的条目里名称或命令为空 | 跳过并计数；全被跳过时按「包为空」处理 |

## 二、格式

```json
{
  "format": "edgeterm-snippets",
  "version": 1,
  "snippets": [{ "name": "Logs", "command": "tail -f app.log" }]
}
```

不带 id：id 是本机的记账，搬到另一台机器上只会撞车。名称按应用同样的规则清洗（去控制字符、去首尾空白、截断），命令按同样上限截断。

## 三、实现

| 位置 | 变化 |
| --- | --- |
| `snippetTransfer.ts` | `exportSnippets` / `importSnippets`（纯函数；三种拒绝原因；按名称去重、末条胜出；条数与长度上限） |
| `storeSnippetActions.ts` | `importSnippets(entries)` 一次合并、一次持久化，返回落地条数 |
| `SnippetsDialog.tsx` | 底部两个按钮与一段提示；失败显示 `.dialog-error` |

## 五、边界与取舍

- 走剪贴板而不是文件：不需要原生保存/打开对话框，也不会在磁盘上留下需要读者自己管理的文件；要落盘时把剪贴板内容粘进任意编辑器即可。
- 不做「只导出选中项」：列表上没有多选，先加多选再谈导出更合理。
- 导入合并语义与手工保存一致（同名覆盖），预览条数由提示给出，不做二次确认——一份 3 条命令的包，不值得一次模态确认。
