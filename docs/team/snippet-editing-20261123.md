# 常用命令的编辑与筛选（2026-11-23 第 47 轮）

第 42 轮起，改一条保存过的命令只能删掉重加。列表到几十条后，找一条也只能滚动。本轮把两件事都补上。

## 一、行为

| 情况 | 结果 |
| --- | --- |
| 点一行的铅笔 | 表单载入该条的名称与命令，按钮变为「保存修改」，旁边出现取消 |
| 保存修改 | 原地更新（id 不变），立即持久化 |
| 改成一个已被别人使用的名称 | 拒绝并说明「已有同名命令，换个名字」，原条目不变 |
| 名称或命令为空 | 「保存修改」保持禁用 |
| 筛选框输入 | 按名称或命令文本实时收窄；无匹配时显示「没有匹配…的常用命令」 |
| 清空筛选 | 恢复完整列表 |

## 二、实现

| 位置 | 变化 |
| --- | --- |
| `storeSnippetActions.ts` | `replaceSnippet(id, name, command)`：校验空值、拒绝重名、原地更新并持久化，返回是否成功 |
| `SnippetsDialog.tsx` | 表单兼编辑器（editingId）；筛选框；无匹配状态；编辑按钮用 `edit` 图标 |
| 本地化 | 新增 6 个键（编辑、保存修改、重名、筛选、无匹配） |

## 五、边界

- 筛选只匹配名称与命令文本，不做模糊评分排序；
- 编辑不改变 id，因此面板与菜单里的同一条命令保持同一个身份；
- 重名判定以去控制字符、去空白后的名称为准。
