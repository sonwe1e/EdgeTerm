# 发送常用命令时说出「发给了几个终端」（2026-11-23 第 68 轮）

同步输入打开时，一条常用命令会写到每一个勾选的终端。此前状态栏只说「Sent: Logs」——**没说是只发了这一个，还是发到了五台机器**。而这正是多主机操作里最需要确认的一件事。

## 一、交付

| 情况 | 状态栏 |
| --- | --- |
| 同步输入关闭 | `Sent: {name}`（不变） |
| 同步输入打开、有其它目标 | `Sent: {name} — to {count} shells`（含来源终端） |
| 同步输入打开、但其它目标全被排除 | `Sent: {name}`（不变：确实只有这一个） |
| 活动标签是文件浏览器 | 沿用同一条拒绝理由，不发送 |

## 二、判断：计数复用同一个目标函数

目标数来自 `broadcastTargets`——与真正写入用的是**同一个**纯函数，不是另写一份筛选。这样「说发的」和「实际发的」不可能分叉；已连接、非文件会话、排除列表、整组排除这些条件都只有一处定义。

## 三、验证

| 用例 | 断言 |
| --- | --- |
| `snippetSend.test.ts`（4，新增文件） | 单个目标只写 `a` 且状态为 `Sent: Logs`；同步开启时状态为 `… — to 2 shells` 且写到了 `b`；`b` 被排除时又回到 `Sent: Logs`；活动标签是 SFTP 时拒绝并给出原因 |

## 四、边界

- 计数包含来源终端（命令确实在那里执行）；
- 只统计已连接、非文件会话的终端，与同步输入本身的定义一致。
