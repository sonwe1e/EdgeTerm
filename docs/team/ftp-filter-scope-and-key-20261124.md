# 双栏筛选：补上「/」键，并证明筛选属于一个目录（2026-11-24 第 82 轮）

第 73 轮给 FTP/SFTP 双栏加了筛选，但只测了「输入筛选、Esc 恢复」，有两条行为没有证据：**筛选在换目录后是否清掉**，以及**键盘能不能进筛选框**。这一轮补齐，并顺手让「/」成为第四处一致的入口。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| 双栏列表 | 列表聚焦时按 `/` 聚焦本侧筛选框（`Ctrl/⌘/Alt` 组合不拦截），其余按键仍交给列表自己的键盘模型 |

到这一轮为止，四处列表的 `/` 行为一致：文件面板、双栏每一侧、会话树、常用命令列表。

## 二、验证（两条都是补证据，不是补实现）

| 用例 | 断言 |
| --- | --- |
| 换目录清筛选 | 夹具里 `path` 由状态驱动：筛成只剩 `file-b.txt` 后把目录切成 `/next` → 筛选框为空、列表回到三条 |
| `/` 进筛选 | 列表聚焦按 `/` → `document.activeElement` 是 `.filer-filter` |

`ftpKeyboard.browser.test.ts` 6 条通过（原 4 条 + 本轮 2 条）。

## 三、边界

- 换目录清筛选只依赖 `path` 变化；同一个目录内刷新不清；
- `/` 只移动焦点，不修改筛选内容。
