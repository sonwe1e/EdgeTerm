## 确认无缺陷

- 重命名差异：staged 重命名两个路径都传（有测试）；标题由 `+++ b/` 最后写入；working 差异对非重命名丢弃 originalPath。
- 空提交信息：编辑器与后端双重拦截，Ctrl+Enter 复查 canCommit。
- 长命令无取消：READ 12s / WRITE 25s 超时；本地 run 在 drop 时杀进程；SSH 捕获超时并终止通道。
- 文案里的分支/引用都与代码一致（`as of the last fetch`、`last 60`、`local branches`、showMore 计数、commitSummary 分组计数）；47 个使用的 git.* 键两语言都有（各 70 键）。
- 失败状态都有出路：loadError 带刷新按钮、history 错误由 refreshAll 清除、branches 对话框有关闭与提示、git.diff.empty 与 git.stale 都点名下一步。
- 状态过期：窗口聚焦、刷新按钮、每个变更的 finally、编辑器关闭都会重读；提交 token 有意不含工作树状态（有测试），过期 token/root 服务端拒绝。

边界：静态读源码，未在真实仓库的冲突状态下点检 GIT1 的渲染效果。
