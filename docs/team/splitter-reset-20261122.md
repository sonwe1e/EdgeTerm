# 拖动条双击还原（2026-11-22 第 20 轮）

一个同一视觉形状、两种行为的不一致：**面板停靠区**的拖动条早已支持双击还原（Splitter 的 onReset 由 App 与 PanelDocks 传入），但**终端分屏**的拖动条只传了拖动回调——同样的双击在分屏上什么都不会发生。

## 一、修复

| 位置 | 作用 |
| --- | --- |
| layout.ts | 新增 resetSplit(node, path, index)：只把被点的那一对均分，保持两者总量，树的其余部分原样 |
| store | resetSplitSizes(path, index)；布局未变化时不触发更新 |
| Workspace | 分屏拖动条传入 onReset，与停靠区同一手势同一结果 |

## 二、验证

| 用例 | 断言 |
| --- | --- |
| 单测 layout.reset.test.ts 4/4 | 根边界均分且总量不变；已经均分时返回同一对象；嵌套边界只重置被点的那一层且另一侧保持同一引用；越界索引不动 |
| 浏览器 splitterReset.browser.test.ts 1/1 | 0.7/0.3 的分屏 → 双击拖动条 → 布局变为 0.5/0.5、两侧宽度差 ≤2px |

全量：前端单测 177 文件／1731 用例、浏览器契约 55 文件／253 用例、typecheck、format:check（534 文件）、lint（仅生成绑定 2 条既有警告）、生产构建全部通过。

## 三、边界

- 只有双击：键盘与菜单暂没有“均分”入口（拖动条本身支持方向键微调）；
- 只重置被点的边界，不重排整棵树；嵌套分屏的其余比例保持不变。
