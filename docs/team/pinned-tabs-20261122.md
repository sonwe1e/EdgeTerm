# 固定标签页（2026-11-22 第 23 轮）

标签一多，最常用的那个会被挤到看不见的位置。本轮加上固定：

- 右键标签 → 固定/取消固定（Pin Tab / Unpin Tab）；
- 固定的标签**移到它所在条带的最前面**并显示一个图钉；
- **Close Others 不关固定标签**——固定是“批量关闭时保住它”的承诺，显式的关闭按钮仍然关得掉。

## 一、实现

| 位置 | 作用 |
| --- | --- |
| Tab.pinned | 标记；固定时用 placeTab 把它移到本面板首位（数组顺序即显示顺序，拖拽重排因此不受影响） |
| toggleTabPinned | 切换并归位；取消固定不再移动 |
| closeOthersTargets | 纯函数：Close Others 要关谁（排除自己与固定项），菜单与单测共用 |
| TabStrip / CSS | 图钉前导、`is-pinned` 类、12px 图标与强调色 |

## 三、边界

- 固定不跨面板迁移：只在本面板内置顶；
- 固定状态不持久化（重启后标签本来就是新的）；
- 没有“只显示图钉”的紧凑模式。
