# 常用命令库（2026-11-23 第 42–43 轮）

第 41 轮的功能面盘点认定「保存常用命令并一键发送」是当前最明显的缺口。第 42 轮做完模型、持久化、存储与弹层，第 43 轮补上可见的关闭出口并完成全量验证。

## 一、行为

| 情况 | 结果 |
| --- | --- |
| 添加命令 | 列表新增一行，写入浏览器存储 |
| 同名再添加 | 替换该名称下的命令，不出现两行同名 |
| 点击一行 | 命令加一个 Enter 通过**输入漏斗**发到当前终端，状态栏报「已发送：名称」 |
| 开启同步输入时点击 | 与手打命令相同的广播规则，不另开路径 |
| 没有已连接的 shell | 拒绝并说明原因（不吞字节） |
| 删除 | 行与存储同时移除 |
| 上限 | 100 条；命令 4000 字符；名称 60 字符 |

## 二、实现

| 位置 | 内容 |
| --- | --- |
| `snippets.ts` | 类型、存储键、校验（丢弃畸形条目而不是改写）、`snippetBytes`（命令 + 恰好一个 Enter） |
| `storeSnippetActions.ts` | `snippets` / `saveSnippet`（按名称 upsert）/ `deleteSnippet`，每次变更即持久化 |
| `snippetActions.ts` | `sendSnippet`：拒绝文件会话与未连接会话，其余走 `sendSessionInput` |
| `SnippetsDialog.tsx` | 列表（名称 + 命令预览，命令作 title）、Add 表单、删除、Close/Esckbd 出口 |
| 菜单 | View 菜单新增「常用命令…」，位于命令走查项之前 |

## 四、明确的边界

- 没有编辑操作：删除后重加（v1 取舍，避免同一功能两套写路径）；
- 命令原样发送，不做变量展开或二次转义——它不是 shell 脚本；
- 命令面板尚未列出命令条目（菜单 + 弹层是唯一入口），留待后续一轮；
- 存储是浏览器 localStorage，与既有偏好一致；没有导出/导入。
