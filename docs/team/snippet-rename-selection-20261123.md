# 改名时名字已经是选中的（2026-11-23 第 76 轮）

上一轮让常用命令列表认 F2。但按下之后只是把表单填好：焦点还留在行上，读者要再点一次输入框、再全选一次才能输入新名字。文件管理器的改名框不会这样——打开时名字就是选中的，直接打字即可。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| 常用命令表单 | 进入编辑（`F2`、铅笔按钮、或双击行为）后，**名字输入框获得焦点且全文选中**：直接打字就替换，按 Enter 保存 |

实现放在 `useEffect(editingId)` 里而不是 `edit()` 内部：`edit()` 只是写状态，随后的渲染会把值写进输入框，而**赋值会把光标移到末尾**。在渲染之后再选中，才是读者看到的那一屏。

## 二、验证

`snippets.browser.test.ts`（23，用例加强）：按 `F2` 后断言 ①表单名字是 `Deploy`；②`document.activeElement` 就是这个输入框；③`selectionStart`/`selectionEnd` 覆盖整个名字（`[0, 6]`）；④`WRITES` 仍为空、列表仍是两条。

## 三、一次自我修正

第一版把 `focus()`/`select()` 写在 `edit()` 里：同步执行时成功，随后 React 写入新值把选择清掉，选择区间对不上。把动作移到 `useEffect` 里，等值落地再选中，一次通过。

## 四、边界

- 只选中名字，不选命令——改命令的人可以按 Tab 过去；
- 取消编辑（Cancel）不改动原行；
- 进入编辑不会发送任何内容。
