# 对话框审计（2026-11-22 第 5 轮）

shell 已经有测量门禁（对比度、点击尺寸、文字截断），但使用者一年只打开几次的对话框没有。本轮把同一套收集器指向它们。

## 一、方法

1. **用真实路径打开**：新建会话/显示设置/快捷键/关于走命令面板（纯键盘）；设置索引走 View 菜单（鼠标）；都在 `dialog[open]` 出现后才测量。
2. **测量三件事**：正文对比度（含堆叠背景）、可点击尺寸（WCAG 2.2 SC 2.5.8 间距例外 + 16px 可用下限）、标签截断。
3. **证明"看到了"**：断言 inspected 下限（正文元素数、可点击元素数），否则空树也会全绿。
4. **用真实 Escape 关闭**：`document.dispatchEvent` 造的键盘事件没有 `target.closest`，会在 App 的快捷键处理里抛错。
5. **小屏复测**：新建会话对话框在 720×560 下不得越出视口。

## 二、发现与处置

| 现象 | 判定 | 处理 |
| --- | --- | --- |
| 快捷键对话框的"清除"按钮 22×22，且相邻目标落在其 24px 圆内 | **真实缺口** | 行网格列与按钮尺寸都改为 24×24，间距随后满足 WCAG 间距例外 |
| 关于对话框只有 1 个实心按钮 | 误报（下限过高） | 可点击元素下限改为 ≥1，正文元素仍要求 >2 |
| 首次运行时"新建会话"审计拿到 null | 测试竞态：命令面板本身是 dialog，面板关闭与新对话框打开之间出现空窗 | 等待"面板输入框消失 **且** 对话框出现"再测量 |
| 菜单标题是中文而查询用英文 | store 的 `language` 字段不等于发布给 `t()`/`useT` 的语言；且 `setState(...initial)` 会把它写回旧值 | 在状态重置**之后**调用 `setLanguage("en")` |

## 五、边界

- 需要后端状态的对话框未覆盖：日志查看器、检查更新、OpenSSH 配置导入、Agent 对话框。
- 传输中心/转发中心是状态栏弹层而非 dialog，本轮未覆盖。
- 对比度收集器对渐变/图片背景返回 indeterminate，按"不可判定"计数而不是失败；测试只断言 issues 为空。
