# 命令行面板里直接连主机（2026-11-24 第 89 轮）

打开命令行面板通常是为了找一条命令。但高频的另一件事是：**现在就连上这台机器**——`root@10.0.0.5`。为此要打开会话编辑器、填主机、端口、用户名、再连接，只有一个主机名的时候尤其啰嗦。

## 一、交付

命令行面板的搜索框兼作目标框：输入能被解析为目标时，**第一行**变成「连接到 …」，回车即开会话。

| 输入 | 结果 |
| --- | --- |
| `example.com` | 连接 `example.com`（默认端口、默认用户名） |
| `root@10.0.0.5` | 以 `root` 连接 |
| `deploy@build-01.lab:2222` | 用户、主机、端口都取输入里的 |
| `[::1]:2222` | 带方括号的 IPv6 |
| `ssh`、`zzzz`、`display settings` | **不是目标**，照旧是搜索（空白、单个词都不当作主机） |

「单个词不算主机」是这一轮踩出来的：第一版任何单词都能解析成主机，于是搜索 `zzzz` 时本该显示的「没有匹配」被一行「连接到 zzzz」顶掉。规则改为**目标必须自己说出来**：有 `@`、有 `:`、主机名带点，或方括号地址。

## 二、不保存任何东西

目标会话用 `newSessionProfile()` 造一份临时资料，只改写主机/端口/用户名与标签名，`id` 留空——连接不会往会话列表里塞一条没被确认的条目。

## 三、验证

| 层次 | 证据 |
| --- | --- |
| 解析 | `src/quickConnect.test.ts`（5 条）：四种写法、单词语句与非法端口被拒绝、标签名与资料填充、未指定的字段保留默认 |
| 面板 | `commandPalette.browser.test.ts`（3 条，新增 1）：`display` 不出连接行；`root@10.0.0.5:2222` 的第一行是「连接到 …」；回车后 store 里出现该名会话，`profile` 的 host/user/port 与输入一致，面板关闭 |

## 四、边界

- 只在命令行面板里存在这一行；会话面板与菜单没有新增入口；
- 没有账号密码时按既有流程弹认证提示；
- 不写入会话列表，所以 `id` 为空的资料不会出现在「已保存会话」里。
