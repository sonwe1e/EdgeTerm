# 命令面板（2026-11-22 第 2 轮）

目标：把"入口收敛"这一项做到领先。Windows Terminal、Termius、Warp 已有命令面板，Xshell、SecureCRT、FinalShell 没有——它是少数能同时改善**可发现性**和**操作速度**的面板，也正好补上本仓库全库检索不到命令面板的空缺。

## 一、设计

- **目录来自既有事实**：快捷键表（`SHORTCUT_COMMANDS`）、面板状态、已打开标签、已保存会话、四套主题、设置对话框。命令的标签复用菜单与快捷键设置的同一条消息键，所以面板里的名字不会和菜单漂移；命令由注入的回调执行，本模块不碰 store。
- **排序阶梯**：完全相等 > 前缀 > 词首 > 子串 > 子序列，命中后加"最近使用"加权；同分保持目录顺序，所以同一串查询的结果稳定。中文界面可以用英文搜索：每条命令都带一份英文标签作为隐藏检索词。
- **分组**：一个分组只出现一次标题，查询为空时按目录顺序，检索时按"该分组最佳匹配"排序；列表的扁平顺序就是方向键行走与 `aria-activedescendant` 的顺序。
- **键盘**：↑↓ 环绕、Home/End 跳转、Enter 执行、Esc 关闭、Tab 关闭。对话框边界、焦点归还、背景点击与 Escape 语义复用 `ModalDialog`（原生 `showModal` 路径 + 文档化的降级路径）。
- **可达性**：输入框是 combobox（`aria-controls` / `aria-activedescendant`），列表是 listbox，行为 option 带 `aria-selected`；分组用 `role="group"` + 标题。
- **最近使用**：注册在 `persistKeys.ts`（`edgeterm.commandPalette.recents`），所以"恢复默认设置"会清空、导出会携带；损坏或被降级的数据只会丢列表，不会让面板失效。
- **入口**：`Ctrl+Shift+P`（macOS `⇧⌘P`）进入可改键的快捷键表（快捷键对话框自动列出），并在 View 菜单顶部加一条"Command Palette…"，带当前键位提示。

## 二、本轮发现并修掉的问题（都由测试实测暴露）

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| React 报重复 key，列表出现重复分组 | 只按"相邻同组"分组，Actions 在目录里出现三次 | 改为按分组 id 聚合，分组内保持排序顺序 |
| 过滤后行数多于页脚计数 | 重复 key 让旧节点残留 | 同上；扁平顺序改为唯一来源 |
| 选中行提示文字 4.37:1 | 选中行给提示与键帽加 `opacity: .82` | 选中行恢复全对比墨色（不透明度 1） |
| serialx-dark 键帽 3.76:1 | 键帽用 `--fg-dim` 压在自己的 `--bg-track` 上 | 键帽墨色改为 `--fg` 与 `--bg-track` 的 88% 混合，四套主题均 ≥4.5:1 |
| 面板把"Command Palette"列为自身命令 | 执行它会重新打开自己 | 目录中排除自身；快捷键设置仍提供它 |

## 三、验证

- `src/commandPalette.test.ts`：28 条（匹配阶梯、排序稳定性、最近使用持久化与容错、目录分组、中英互搜、分组扁平化与页脚计数一致、自身不出现在列表）。
- `src/components/CommandPalette.test.ts`：8 条（打开焦点、过滤、方向键环绕与 aria、Enter 执行并记最近、点击执行、Esc/Tab 关闭、重开清空、键帽显示）。
- `src/test/commandPalette.browser.test.ts`：2 条真实 Chromium 契约——真实按键打开原生模态、输入过滤、四套主题的对比度审计全空、指针/键盘目标审计全空、Enter 执行并把主题改成 light、最近使用落盘、Escape 关闭且不执行命令。
- 全量：前端单测 170 文件／1699 用例、浏览器契约 42 文件／215 用例、typecheck、format:check（508 文件）、生产构建全部通过。

## 四、边界

- 只在 Chromium + 受控 IPC 下验证；WebView2、真实中文 IME 组合输入、真实服务器未验。
- 目录规模约 30–40 条，未做性能基准（线性排序足够）；会话很多时未测长列表滚动体感。
- 传输中心、转发中心、Agent 面板的深层动作暂未纳入；它们目前由各自面板承担。
