# 常用命令列表也认 F2（2026-11-23 第 75 轮）

上一轮给会话树加了 F2。常用命令列表（管理器弹层）里，改名要走每行的铅笔按钮：能用方向键走动的列表，却唯独改名要拿鼠标，这正是「一条路径只有一半」的情形。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| 常用命令行 | `F2` 把光标所在行载入表单——与点铅笔按钮完全同一条路径（`edit(snippet)`） |

没有另做「就地改名」：这个列表中一行有两块内容（名字 + 命令），改名与改命令本来就共用一张表单，`F2` 只是把表单填好、焦点交给读者。

## 二、验证

`src/test/snippets.browser.test.ts`（23，新增 1）：两条命令的夹具，焦点放到第二行，按 `F2` → 表单里的名字是 `Deploy`；并断言**没有发送**（`WRITES` 仍为空）、列表仍是两条。

## 三、边界

- `F2` 只填表，不保存：读者仍要按「Save Changes」；
- 行上的 Delete / Backspace / 方向键行为不变。
