# 常用命令的参数（2026-11-23 第 46 轮）

常用命令保存下来之后，同一行里往往只有一两个词会变：`deploy {{env}} --tag {{tag}}`。本轮让命令可以带参数，发送前询问并填入。

## 一、行为

| 情况 | 结果 |
| --- | --- |
| 命令里没有 `{{…}}` | 直接发送，与之前一致 |
| 命令里有参数 | 打开询问框：标题带命令名，预览显示原命令，每个参数一个输入框 |
| 值没填全 | Send 按钮保持禁用 |
| 填全后发送 | 命令用值替换占位符后发出（`deploy prod --tag v9`），只加一个 Enter |
| 取消 / Esc | 什么都不发，不留下半条命令 |

## 二、为什么用 `{{name}}` 而不是 `${name}` 或 `{name}`

片段内容基本是 shell 文本：`${VAR}` 是 shell 自己的展开，`{}` 出现在 `awk`、`find`、`sed` 里。判定「哪些花括号是我们的」只能靠语法猜测，猜错就会改坏命令。`{{name}}` 在 shell 文本里罕见，且未闭合的 `{{` 原样保留。

## 三、实现

| 位置 | 变化 |
| --- | --- |
| `snippets.ts` | `templateNames` / `expandTemplate`（去重、按出现顺序、名称去空白、空值保留占位符） |
| `SnippetArgsDialog.tsx` | 新对话框：预览 + 每参数一个字段 + 填全才可发送 |
| `App.tsx` | 唯一的入口 `runSnippet`：无参数直接发，有参数开询问框；弹层与命令面板都走它 |

## 四、验证

| 用例 | 断言 |
| --- | --- |
| `snippetTemplates.test.ts`（5） | 参数去重按出现顺序；替换；缺值保留占位符；`awk '{print $1}'` 与其他花括号不动；未闭合原样；名称内空白被去除 |
| `snippets.browser.test.ts`（6，新增 1） | 弹层里点带参数的片段 → 标题「Fill in Deploy」、预览原命令、两个字段 `env`/`tag`；缺一个值时 Send 禁用；填全后发送，IPC 收到 `deploy prod --tag v9\r`，询问框关闭 |

## 五、边界

- 不保存上次填过的值（每次重新问，避免把上次的 `prod` 悄悄用于下一次）；
- 值不做转义：填入什么就发送什么，包含空格即一个参数（使用者决定引号）；
- 同一参数出现多次会一起替换（`templateNames` 去重，替换作用于全部位置）。
