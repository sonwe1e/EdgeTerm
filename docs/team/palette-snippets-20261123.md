# 常用命令进入命令面板（2026-11-23 第 44 轮）

第 42–43 轮把常用命令做进了菜单与弹层。对键盘优先的读者，弹层仍然是「点鼠标」的路径。本轮把命令放进命令面板，并补上「把上一条命令存为常用命令」。

## 一、行为

| 面板条目 | 结果 |
| --- | --- |
| `Send <名称>` | 按组合键打开面板、输入名称、回车即发送；与手打命令走同一条输入漏斗 |
| `Save Last Command as a Snippet` | 有已完成的命令时打开命名框，保存为常用命令 |
| 同上，但没有可保存的命令 | 状态栏说明「还没有可保存的已提交命令」，不弹空框 |

两个条目都可被命令自身的文字搜到（片段名称、命令文本、`snippet`），中英文界面都能用英文关键词命中。

## 二、实现

| 位置 | 变化 |
| --- | --- |
| `commandPalette.ts` | `PaletteSources.snippets` 与两个动作（`sendSnippet` / `saveLastCommandAsSnippet`），条目 id 用 `snippet:` 命名空间 |
| `App.tsx` | 传入片段列表与两个动作；命名框复用既有的 `GroupNameDialog`（只换标题/标签/提示） |
| 本地化 | 新增 6 个键（发送、保存、保存提示、无命令、已保存、保存按钮） |

## 四、上一轮记为缺口的那一处，已补上

第 44 轮把「保存上一条命令」的成功路径记为已知缺口。第 45 轮用断言式探针查明原因：**调用顺序**。命令跟踪器在 `noteCommandSent` 时开始一次命令；此后 shell 的 OSC 133 C 会被忽略（已经在跑）。所以正确的顺序是：

1. `noteCommandSent("echo hi")`（app 在 Enter 时做的事）；
2. 写 `OSC 133 C`（shell 宣布开始）；
3. 写 `OSC 133 D;0`（shell 宣布结束）→ `lastCommandText()` 为 `"echo hi"`。

第 44 轮写的是「C → noteCommandSent → D」：C 已经把命令以空文本开跑了，note 被忽略，于是得到空字符串。

现在浏览器用例覆盖完整链路：面板 → 命名框（提示里带命令原文）→ 提交 → 存储里出现 `{name: "Greeting", command: "echo hi"}`；另有一条覆盖「没有可保存命令」的拒绝路径。
## 五、边界

- 片段条目出现在 `actions` 组；没有单独的「常用命令」分组（分组是面板的固定目录，新增分组要动 6 处标签）；
- 面板不提供删除/编辑片段：那是弹层的事，两处各做一套编辑会分叉。
