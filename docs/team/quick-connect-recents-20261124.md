# 最近连接过的机器（2026-11-24 第 91 轮）

第 89–90 轮让命令行面板的搜索框可以直接当目标框用。但它只帮第一次：同一台机器第二天还要重新敲一遍地址。

## 一、交付

- 从面板连上的目标**记进本地偏好**（键 `edgeterm.quickConnect.recents`，注册进 `PANEL_PREFERENCE_KEYS`，因此「恢复默认设置」会清掉、导出会带走、导入会认）；
- 只记**标签**（如 `root@10.0.0.5:2222`），不记密码、不记资料；上限 4 条，重复的前移；
- 面板里这些目标作为普通命令参与**排序**（不硬塞到第一位），提示行写明「最近连接过」，回车即重连；
- 存储里的内容一律校验：不是 JSON、不是数组、含非字符串、重复项都丢掉，读失败只是没有最近记录，不会影响连接。

## 二、为什么排在排序里而不是置顶

第一版把它们插在列表最前面，浏览器用例立刻失败：空查询时列表按**分组顺序**重排（动作 → 布局 → 面板 → 标签 → 会话 …），插入位置被分组覆盖。于是改为随排序走：不打断既有分组结构，输入 `10.0.` 这类**不是目标**的片段也能把它们搜出来。测试用的正是 `10.0.`——主机名不能以点结尾，所以这一行只可能来自记忆。

## 三、验证

| 层次 | 证据 |
| --- | --- |
| 存储 | `src/quickConnectRecents.test.ts` 5 条：新在前、重复前移、上限、读垃圾不炸、写失败不炸、往返 |
| 面板 | `commandPalette.browser.test.ts` 3 条（新增断言）：连过之后输入 `10.0.`，出现「连接到 root@10.0.0.5:2222」且提示为「最近连接过」 |

## 四、边界

- 只是最近**目标**列表，不是会话资料：不清空、不进入会话列表、没有密码；
- 每条上限 4 个，避免把面板变成一个收件箱；
- 删除方式：恢复默认设置（键已注册），或换一台机器不用它。
