# 终端字号快捷键（2026-11-22 第 21 轮）

每个终端都有按住 Ctrl 加减号的即时缩放；EdgeTerm 之前要打开显示设置对话框才能改字号——为了一次两秒的调整点三次。本轮补上：

| 和弦（可改键） | 作用 |
| --- | --- |
| Ctrl+= / ⌘= | 终端字号 +1px |
| Ctrl+- / ⌘- | 终端字号 -1px |
| Ctrl+0 / ⌘0 | 回到默认 14px |

View 菜单里有同名三项；状态栏显示当前字号（例如 Terminal font 16px）。

## 一、实现要点

- 缩放改的就是显示设置里那个偏好（bufferFontSize），没有第二份状态：对话框与和弦永远一致，并且都写同一个 localStorage 键；
- 上下限由 store 的 setter 统一钳制（8–32），和弦只负责算出目标值；
- 状态栏报告的是钳制后的值，所以到顶后继续按会看到 Terminal font 8px，而不是一个没生效的数字。

## 二、验证

fontSizeKeys.browser.test.ts 1/1，按真实和弦断言六件事：

1. 两次 Ctrl+= 让 14 → 16；
2. localStorage 写入 16；
3. App 重新发布 --buffer-font-size: 16px；
4. 渲染出的行区域确实变高；
5. Ctrl+0 回到 14 并写回；
6. Ctrl+- 到 13，以及在下限处继续按仍是 8 且状态栏同步。

## 三、边界

- 只覆盖终端缓冲区字号；面板字号仍由显示设置管理；
- 没有 Ctrl+滚轮缩放（只做了键盘）；
- 只覆盖 Chromium 与受控 IPC。
