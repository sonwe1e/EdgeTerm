# Esc 先从编辑里退一步（2026-11-23 第 77 轮）

在常用命令管理器里点「Edit」或按 F2 之后，读者正在改一条命令；这时按 Esc 会把**整个管理器关掉**，改到一半的内容无声消失。管理器本来就是 Esc 先清筛选、再关窗（第 11 轮）的两级结构，编辑是同一类「读者正身处其中」的地方。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| 管理器关闭路径 | 有编辑在进行时，Esc 与「Close」按钮**先退出编辑**（丢弃表单内容、回到空表单），再按一次才关窗 |

只对**已存在**的条目生效（`editingId !== null`）。写一条全新的命令时，表单里没有可「退回」的对象：这时 Esc 仍然直接关窗，与以前一致——对话框不该把读者困在里面（`ModalDialog` 的既有约定）。

## 二、验证

`snippets.browser.test.ts`（24，新增 1）：点「Edit Deploy」进入编辑 → `Esc` → ①管理器仍在（标题还在）②表单已清空 ③列表里的条目**未被改动**；再 `Esc` → 管理器关闭。

## 三、边界

- 新建命令途中按 Esc：仍然关窗（不困住读者）；
- 筛选中按 Esc：仍按原规则先清筛选（三级：筛选 → 编辑 → 关窗，每一级只退一步）。
