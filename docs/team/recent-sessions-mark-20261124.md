# 命令面板标出最近连过的会话（2026-11-24 第 96 轮）

会话列表一长，读者每次都要按名字从头找。既有资料里没有「收藏」这类字段，而让人手工维护一份收藏又是额外负担。这一轮改成**记录实际发生过的事**：连过哪个已保存会话，就在面板里标出来。

## 一、交付

- 新模块 `src/recentProfiles.ts`：上限 6 个 id、新在前、去重、读写存储（键 `edgeterm.recentProfiles`，注册进 `PANEL_PREFERENCE_KEYS`，所以恢复默认会清、导出会带、导入会认）；
- store 新增 `recentProfiles` 与 `rememberRecentProfile(id)`；连接成功（`applyState(id, "connected")` 之后）记录 `profile.id`——**没有 id 的临时目标不记**（那是第 91 轮「最近连接过的目标」的职责，按标签记）；
- 命令面板的会话行在提示里加「最近用过」，顺序为「类型 · 地址 · 最近用过 · 连接」——标记是**追加**，不替换地址和动作说明；
- 恢复默认设置清空内存里的列表，导入设置后重新读入。

## 二、不做的部分

- 不新增「收藏」字段：那需要读者手工维护，而且与「最近用过」回答的是同一个问题（我现在在用哪些）；
- 不重排会话列表：排序一改，肌肉记忆就变了。标记只加信息，不动位置。

## 四、边界

- 只在连接**成功**时记录；连接失败、主机密钥变更、被取消都不会让一个会话变成「最近用过」；
- 只影响命令面板；侧栏会话树不动（改树的排序或分区要动键盘导航与大量既有用例，另起一轮再说）。
