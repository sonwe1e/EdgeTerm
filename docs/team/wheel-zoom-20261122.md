# Ctrl+滚轮缩放与字号助手（2026-11-22 第 22 轮）

第 21 轮加了字号和弦，边界里写着“没有 Ctrl+滚轮缩放”。本轮补上，并把缩放规则收进一个纯函数，让和弦与滚轮不可能漂移。

## 一、交付

- **Ctrl/⌘ + 滚轮**在终端上缩放字号（上滚变大、下滚变小），并阻止浏览器把整页缩放；
- **zoomFontSize(current, steps)**：唯一的一步缩放与钳制规则（8–32），和弦与滚轮都走它；
- View 菜单补上**重置终端字号**（Ctrl+Shift+0 / ⌘⇧0），与上/下两条并列。

## 二、验证

| 用例 | 断言 |
| --- | --- |
| 单测 fontZoom.test.ts | 一步一像素；上限、下限与跨过多步的钳制 |
| 浏览器 fontSizeKeys 第 2 条 | 普通滚轮不缩放、也没有被 preventDefault；Ctrl+滚轮上滚 → 14→15 且 defaultPrevented 为真（页面不会跟着缩放）、App 发布 15px；两次下滚 → 13 且状态栏同步 |

普通滚轮那条断言是负向对照：如果实现无差别拦截滚轮，它会在“没有被 preventDefault”这一步失败。

## 三、边界

- 只覆盖终端缓冲区（面板字号仍由显示设置管理）；
- 滚轮步长固定 1px，不随 deltaY 大小加速；
- 只覆盖 Chromium 的合成滚轮事件。
