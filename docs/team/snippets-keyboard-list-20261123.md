# 常用命令列表的键盘走查（2026-11-23 第 57 轮）

一个只能靠 Tab 逐个穿过的列表，键盘读者用不久。常用命令弹层此前每行三个按钮（发送、编辑、删除），全部落在 Tab 顺序里：两条命令就要按 6 次 Tab 才能在它们之间挪动。

## 一、行为

| 按键（焦点在某一行的发送按钮上） | 结果 |
| --- | --- |
| `↑` / `↓` | 走到上一条 / 下一条的发送按钮；到边界不动 |
| `Enter` / `Space` | 发送该行（原有行为） |
| `Delete` / `Backspace` | 删除该行，并把该行从编辑状态里退出（如果正在编辑它） |
| `Tab` | 仍按原顺序走：发送 → 编辑 → 删除 → 下一行 |

## 二、两条判断

1. **Backspace 在行上是安全的**：行里的按钮不会接收文本，Backspace 在按钮上本来什么都不做；只在名称/命令输入框里才有退格含义。因此在这里把它当作删除，不会和打字冲突。
2. **删除不需要确认**：与既有的删除按钮一致——删掉一条保存的命令是可重新输入的，加一道确认只会让清理变慢。

## 三、验证

| 用例 | 断言 |
| --- | --- |
| `snippets.browser.test.ts`（12，新增 1） | 聚焦第一行；`↓` 到第二行、`↑` 回第一行；`Delete` 后列表只剩 `Deploy`，且**没有任何写入**（删除不是发送） |

## 四、边界

- 方向键不跨过筛选后的边界（`visible` 是当前可见列表）；
- 删除后焦点落在浏览器默认位置（下一行按钮或表单），本轮不做「删除后自动聚焦相邻行」——那是另一种约定，需要单独决定。
