## 发布前仍需明确的限制

1. Windows Tauri/WebView2、原生中文输入法、Ubuntu 18.04 SSH/实际 Bash 与 tmux/Vim/OpenCode 的联合验收尚未完成。合成 IME 和 Chrome 回归不能替代它。
2. 外部编辑的同步快照仍是 mtime + size；同长度且 mtime 未变化（包括时间戳粒度或保留时间戳）的变化，以及关闭时文件系统 stat→remove 的竞争，并无绝对防丢证明。崩溃时宁可多保留活动副本。
3. 已提交的后台传输拥有独立生命周期；关闭 tab 阻止后续 watcher 注册/应用打开，不等于取消已在执行的上传。应用退出由传输确认保护。
4. 编辑远端文本现在要求服务端返回 size 且最终 fstat 成功；不支持这一元数据契约的服务器会明确拒绝编辑，而不是返回空/部分内容。未知权限类型仍兼容。完整长度与元数据复核不是远端原子快照；同 size 且 mtime 缺失或未变化的并发改写不保证检出。
5. 原生后端 state 事件只有 session ID；本轮屏障保护取消/清理期间的旧 owner，没有把它改造为跨协议事件令牌系统。
6. “顶尖美观”不是可由测试数量证明的结果。本轮已对明确列出的 CI 实际截图做人工和独立审阅；900px 三栏密度与长子菜单覆盖父层仍是视觉/操作取舍，更大视觉改版需要独立产品决策，不能夹入稳定性修补。
