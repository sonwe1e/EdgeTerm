# 启动命令发不出去时，说一声（2026-11-23 第 67 轮）

启动命令在连接后 400ms 发送，写入失败此前是 `catch(() => undefined)`——**静默失败**。读者专门设了这一行，就是为了让会话落在正确的目录里；它没发出去却什么都不说，是最坏的一类失败。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| `actions.ts` | 写入失败改为在状态栏报「Startup command could not be sent: {error}」 |
| 文案 | 中英文各一条（`session.startupFailed`） |

## 二、判断：成功不吭声，失败必须说

命令成功时终端里会回显，不需要额外提示；失败时屏幕上什么都没有，只有状态栏能说清。这与第 62 轮「重跑历史命令成功时不出声」是同一条原则的两面：**结果已经在屏幕上的动作不报，结果应当出现却没有出现的动作要报**。

## 四、边界

- 只覆盖「写入失败」；「标签在 400ms 内被关闭」仍静默（读者自己关的，不需要解释）。
- 状态栏消息与其它失败一样，会被下一次状态更新替换；没有另建通知历史。
