# 第 100 轮：把上轮记下的缺口关掉（2026-11-24）

上一轮我在文档里留了一个缺口：**最小面板尺寸下，空窗口的最近会话列表可能超出可视高度**，并说明没有顺手改样式。这一轮先确认它到底是不是缺陷。

## 一、结论：不是缺陷，是测试手法的限制

`.term-empty` 本身就有 `overflow: auto`：整个空状态作为一个滚动容器，放不下时整体滚动。新增用例在 378×465 / 18px 的实测尺寸下断言：

- `scrollHeight > clientHeight`（确实放不下、确实在滚）；
- 把「最近用过」的条目 `scrollIntoView({ block: "nearest" })` 之后，它的上边不低于面板上沿、下边不低于面板下沿 3px——**它进得来、也看得见**。

于是上一轮的点击超时是 **Playwright 在自有滚动容器里的指针定位限制**，不是被裁掉的界面。没有改任何样式。

## 二、写进决策的两条

- **D108**：空窗口复用既有 `.term-empty-entry` 结构展示最近会话；空状态整体是一个滚动容器，不为它单独加样式。
- **D109**：文档里记下的「疑似缺口」必须先量一次再决定改不改；量完是测试限制，就写成测试限制，不要为了关掉一条待办去改产品。
