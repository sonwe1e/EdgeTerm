# 空列表不是死胡同：说明两条更快的保存路径；Esc 先退筛选（2026-11-23 第 66 轮）

常用命令弹层第一次打开是空的，只写「在下面添加一条」——读者刚跑完一条命令，最想保存的其实是**屏幕上那条**，而这条路径没人告诉他。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| 空列表 | 第二行（更暗、更小）：「也可以在终端里右键『把上一条命令存成常用命令』，或用命令行面板保存刚跑过的那一条」 |
| 筛选框 | `Esc` 先清空筛选，**再按一次**才关闭弹层 |

## 二、两个判断

1. **指导只出现在空列表**：有了条目就撤掉，否则那会变成一段永久占据版面的说明。
2. **`Esc` 是一步退，不是关门**：筛选是读者走进去的一层，先退回整表符合直觉；第二次按才退出弹层（与 ModalDialog 既有行为一致）。

## 三、验证

| 用例 | 断言 |
| --- | --- |
| `snippets.browser.test.ts`（21，新增 2） | 空列表含「Nothing saved yet」与「Save Last Command as a Snippet」两条指引；保存一条后指引消失；筛选无匹配时按 `Esc` → 筛选清空、弹层仍在；再按 `Esc` → 关闭 |

## 四、边界

- 只在筛选框有内容时才拦截 `Esc`；筛选为空时 `Esc` 直接关闭（保持原有行为）。
- 提示文案里的入口名与菜单/面板实际文案一致（同一 `palette.saveSnippet` 措辞），避免三处不同说法。
