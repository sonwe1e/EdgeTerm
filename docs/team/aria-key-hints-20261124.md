# 让读屏软件也知道树自己的两个键（2026-11-24 第 113 轮）

会话树的 ARIA 一直只有 `role="tree"` 和 `aria-activedescendant`。方向键、Home/End 是树模式自带的约定，不需要声明；但 **F2（重命名）、空格（折叠/展开）**、以及筛选框的 **`/`** 都是这个应用自己的键，此前只写在文档和快捷键设置里。

## 一、改动

| 元素 | 属性 |
| --- | --- |
| 树容器 | `aria-keyshortcuts="F2 Space"` |
| 筛选框 | `aria-keyshortcuts="/"` |

属性很窄：只声明「这些键在这里起作用」，不改变任何行为、样式或键盘逻辑。方向键刻意不列——那是树的模式约定，列出来会稀释真正需要提示的两个键。

## 三、一次自纠

第一次把说明写成 JSX 开标签里的 `//` 注释——`tsc` 与 Biome 都没报错，但这不是 JSX 的注释写法。改成标签上方的 `{/* … */}`：**能编译不等于写得对**，尤其是这种会被别人照着抄的地方。

## 四、边界

- 只覆盖树与筛选框这两个「有自定义键」的元素；会话对话框、文件面板等的自定义键尚未声明，属于同类工作的下一步。
- `aria-keyshortcuts` 的语法按规范用空格分隔多个组合键；`F2`、`Space` 都是合法的键名。
