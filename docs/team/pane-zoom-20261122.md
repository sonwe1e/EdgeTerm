# 面板放大（2026-11-22 第 18 轮）

分屏之后，读者经常只想看其中一块：跑构建的那块、看日志的那块。本轮加上放大/还原：

- Ctrl+Shift+Z（Mac ⇧⌘Z）或 View 菜单的 Zoom Pane：当前焦点面板铺满终端区；再按一次还原；
- 放大是视图状态，不是布局改动——布局树不动，所以还原时分割比例与之前一模一样；
- 放大期间新建分屏会先自动还原：否则新面板看不见，像是没生效。

## 一、两个实现上的要点

**为什么不是 Enter 和弦。** 最初选的是 Ctrl+Shift+Enter（iTerm2 的习惯），测试证明它到不了应用：终端的键盘处理在匹配快捷键之前就把 Enter 当输入转发了。改用字母键后才可靠。

**隐藏而不是卸载。** 其它面板的会话用 display none 隐藏，而不是从渲染树里移除：xterm 的滚动缓冲活在它的 DOM 元素里，卸载就等于丢掉历史。测试直接断言隐藏后该会话的终端元素仍然连接。

## 二、实现

| 位置 | 作用 |
| --- | --- |
| store | zoomedPaneId + toggleZoomedPane()；空或失效 id 回退为分屏视图；splitPane 清除缩放 |
| Workspace | 面板与其会话共用一个 paneRect()：被放大的面板拿整块矩形，其它面板不渲染、其会话隐藏 |
| shortcuts / MenuBar | 新命令 zoomPane，和弦进菜单与面板 |
| icons | 新增 screen-full 图标 |

## 三、验证

zoomPane.browser.test.ts 1/1：两块面板各占一半 → 按和弦 → 只渲染一个面板、其会话宽度等于终端区宽度、另一块会话隐藏但仍挂载、分割条消失 → 再按 → 两块恢复、宽度回半、分割条回来。

## 四、边界

- 放大没有过渡动画（瞬时切换），也没有状态栏指示；
- 只覆盖 Chromium 与两块面板的横向分割；
- 缩放状态不持久化，重启回到分屏。
