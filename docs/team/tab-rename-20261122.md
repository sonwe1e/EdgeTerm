# 标签页重命名（2026-11-22 第 26 轮）

用户的原话：每个标签都是服务器的名字，有点无法判断这些都是什么内容。

此前标签标题只来自会话名（服务器名），同时开几台机器、每台上跑不同东西时，条带读不出「这个标签在做什么」。本轮允许给标签起自己的名字。

## 一、怎么用

| 入口 | 操作 |
| --- | --- |
| 双击标签名 | 名字就地变成输入框 |
| 聚焦标签后按 F2 | 同上 |
| 右键菜单 | Rename Tab… / Reset Tab Name（恢复会话名，无自定义名时置灰） |

Enter 或点击别处提交；**Escape 放弃**这次输入。自定义名会**取代序号后缀**（web (2) → staging web）：起名的目的就是不再靠后缀猜。可访问名、tooltip、命令面板里的标签项都跟着改。

## 二、实现要点

- `Tab.title`（内存态）与 `renameTab(id, title)`；空或纯空白等于清除，回到会话名；
- `tabTitle()` 是唯一读法：自定义名优先，否则依旧是「会话名 + 序号」；
- 输入框是非受控的就地编辑，pointerdown/click 都被拦下，避免触发标签拖拽；
- 条带为拖拽捕获了指针，浏览器自己的 dblclick 不可靠，因此双击由**两次按下**（400ms 内、同一标签）识别，事件层与指针层各留一条路。

## 三、顺带修掉的一个真实问题

浏览器测试里输入 deploy db 只落下 dep：终端控制器的 rAF 自动聚焦在 xterm 稍晚加载时抢走了输入框焦点，blur 随即按前缀提交。修法是**自动聚焦不得抢走用户正在输入的字段**（xterm 自带的隐藏 textarea 除外）。这不是测试瑕疵，而是同一次真实输入会丢掉后半截的缺陷。

| 用例 | 断言 |
| --- | --- |
| 单测 tabRename.test.ts 4/4 | 默认显示会话名与序号；自定义名取代两者并去空白；重命名去空白、纯空白清除；未知 id 不改动数组引用 |
| 浏览器 tabRename 1/1 | F2 → 输入框带当前名 → 输入并 Enter → 标签显示新名、store 与可访问名同步；再次进入按 Escape → 名字不变；reset 后回到会话名，相邻标签不受影响 |
| 回归 | 焦点相关 12 个既有用例在修复后全部通过（守卫不误伤终端的隐藏 textarea） |

## 六、独立评审后的修复（同轮）

另派只读评审 agent 复查本轮改动，报回 8 条，逐条核实后修复：

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | 中文输入法里 Enter 选词会误提交、Escape 会误取消 | keydown 先看 `isComposing`，组字中不处理 |
| 2 | 输入框打开时未全选，第一下输入是拼接而非替换 | `onFocus` 全选 |
| 3 | Enter/Escape 后焦点落到 `<body>`，后续按键丢失 | 提交后把按键交给该标签的 shell（与点击标签同一去处），取消后留在标签上 |
| 4 | 在序号/间隙上双按也会弹出输入框并立刻关闭（提交了默认名） | 双按只在标签名上生效，并 `preventDefault` 阻止兼容 mousedown 抢焦点 |
| 5 | 命令面板仍显示/搜索会话名，改名后搜不到 | 面板投影改用 `tabTitle` |
| 6 | F2 后直接 Enter 会把派生名冻结成自定义名 | 与当前显示名相同（含序号形式）视为清除；值未变则不改动数组 |
| 7 | 连接成功的状态栏丢掉自定义名 | 用完整 tab 生成名字 |
| 8 | 固定标签从别的面板拖入时，落点上限少一格（目标已有 ≥2 个固定标签） | `clampStripIndex` 增加「来客」参数，落点标记同步 |

顺带补上评审提到的可达性缺口：F6 把焦点交给条带容器本身时 F2 也能改名（此前要先 Tab 一次）。

浏览器用例重写后覆盖：全选后输入是替换、Enter 后焦点回到标签、条带级 F2、序号区双按不改名、标签双按改名、清空恢复会话名；这些断言在修复前都会失败（例如「替换」会断言得到拼接结果）。

未修（记录为边界）：自定义名不随工作区快照持久化（与 `number`/`ordinal` 不同）；F2 目前是菜单里的展示字符串，未进入可改键的快捷键表。

## 五、边界

- 自定义名不持久化（重启后标签是新的）；
- 只改标签显示名，不改会话或配置文件本身的名称；
- 不校验重名；过长名称按条带既有省略规则截断。
