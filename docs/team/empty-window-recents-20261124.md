# 空窗口也是一个入口：列出最近用过的会话（2026-11-24 第 99 轮）

关掉所有标签后，工作区显示品牌、快捷键提示与两个能力入口（文件面板、发送面板）。第 91–97 轮攒下的「最近连接过的目标 / 最近用过的会话」数据，在这个最需要它的窗口里反而没露面。

## 一、交付

- 空窗口在能力入口下方列出**最多 3 个最近用过的已保存会话**，每个是一个按钮：名字 + 「最近用过的会话」，无障碍名 `打开 <名字>`；点击即连接（App 传入的回调走 `openSession`）；
- 复用既有 `.term-empty-entry` 结构：没有新增样式、没有新增量级（字阶、圆角、配色都不变）；
- 没有最近记录时不渲染任何东西——首次启动仍然只有两条进入路径，不摆空列表。

## 二、测试暴露的两个尺寸问题

1. 直接在页面根节点挂 `Workspace`（没有 `.app` 容器）时它没有高度，空窗口被排到视口外，点击超时；夹具改为与其他用例一致：`div.app` 带明确尺寸；
2. 在最小面板尺寸（378×465、18px 字号）下，这个列表比窗口高，按钮被裁掉一半——**点击**测不了。所以新增用例用正常窗口尺寸，最小尺寸下的排版仍由本文件既有那条用例覆盖。

## 四、边界与一个待解的小事

- 只列已保存会话，不列临时目标（临时目标没有名字，在空窗口里更像一行地址）；
- **缺口**：最小面板尺寸下最近会话列表可能超出可视高度。本轮只用正常尺寸的用例覆盖了点击；是否要在窄窗口隐藏该列表或让它内部滚动，留给下一轮决定（不在这轮顺手改样式）。
