## 审计明确说「无缺陷」的部分

- 主机密钥对话框与重连路径：Esc/Cancel 可关闭、Cancel 拿初始焦点、显示的 known_hosts 行号是真实 1-based 行、重连会先刷新 profile 并聚焦终端。
- 标签重命名与取消：Esc 还原不提交，提交与取消都把焦点交回 shell 或标签本身，名字会持久化。
- 导入/导出量级、更新检查路径未发现与后端不一致之处（除上表已列）。
