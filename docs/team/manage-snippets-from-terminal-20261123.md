# 终端右键菜单也能打开常用命令管理（2026-11-23 第 65 轮）

右键菜单里能「发送已保存命令」「保存上一条命令」「发送最近命令」，但想**改一条**或**删一条**，就得先想起命令行面板。管理入口缺失，等于让读者在终端里走到一半再绕路。

## 一、交付

| 位置 | 变化 |
| --- | --- |
| `snippetActions.ts` | 新增打开管理器的注册（`registerSnippetOpener` / `requestSnippetsOpen`），与运行、保存两个注册同形；没有注册者时是安全空操作 |
| `useSnippetRunner.tsx` | 同一个 effect 里注册三个入口，对话框仍只属于这个特性（D68） |
| `TerminalPane.tsx` | 菜单新增「Saved Commands」（有/无已保存命令两种分支都加），不受连接状态限制——管理命令与是否有活动 shell 无关 |

## 二、判断：管理不该依赖连接

「上一轮保存」「发送常用命令」都要求已连接；但**管理**是纯编辑动作。断线时读者更需要整理命令库，而不是被告知「先连上」。因此这一项始终可用。

## 三、验证

| 用例 | 断言 |
| --- | --- |
| `snippetRunner.test.ts`（6，新增 2） | 已注册的打开者被调用一次；未注册时请求不抛错 |
| `snippets.browser.test.ts`（19，新增 1） | 右键终端 → 菜单有「Saved Commands」→ 点击后管理器打开（标题为同名） |

## 四、边界

- 管理器与面板打开的是同一个对话框实例，没有第二份状态；
- 菜单里不重复列出全部命令（只有 15 条的「发送」子菜单），完整列表在管理器里。
