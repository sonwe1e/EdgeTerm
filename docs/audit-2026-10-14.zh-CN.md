## 尚未覆盖，不能签字通过的范围

1. 原始卡死的真实 Performance profile：WebView2、WebGL/DOM、1/8 标签、3000/20000 行、横/纵/对角 splitter。当前只证实 resize 契约与输出额度，不能认定原始 GPU/主线程卡死根因。
2. macOS/Linux、真实串口（尤其无硬件流控时）、真实 SFTP/FTP 服务差异、权限保留、MFA/跳板、远程编辑保存、离线清理后的重连。已有协议夹具/本地 PTY 不替代这些环境。
3. 文件变化检测的强度：本地/SFTP source signature 使用元数据与首尾采样，FTP 使用 size/mtime；恢复前缀另做校验。不能承诺侦测所有保持元数据且只修改文件中部的并发写入，亦不提供跨进程事务锁。源文件应保持稳定。
4. dark 主题浏览器验收已执行；light 主题、全部取消手势和操作系统原生跨应用拖拽仍在[测试矩阵](test-plan.zh-CN.md)中。
5. memo、cached lowercase 和 App 订阅收窄的独立性能收益尚无同语义 release 前后 profile。保留合理机制，但不沿用历史夸张倍率。

这些项目不是本次已发现但隐瞒的“通过”；它们是重提 PR / 发布前应按范围选择的验收条件。后续记录使用“通过 / 失败 / 未运行”，不要再次用一次全绿单元测试取代它们。
