# EdgeTerm 1.7.0

相对上一个公开版本 **1.6.1** 的更新，面向 Windows x64。本版加入 Agent 提示词输入面板，并包含此前仅作本地构建的 1.6.2 改进。安装版沿用应用标识、配置目录和凭据存储，没有数据格式迁移。

## Agent 提示词与终端选区

- 标签栏的 **Agent 提示词** 打开底部草稿框，支持多行、空行、缩进和按终端保留草稿。Enter 换行，Ctrl+Enter 将整段文字放入当前终端；在终端检查后再按 Enter 提交。
- **加入终端选区** 可引用普通终端选区，以及 Codex 等全屏程序接管鼠标后的普通拖选。Shift 拖选后，移动鼠标到按钮不再清除终端高亮；展开面板引起的尺寸变化也不会丢失已保存的选中文字。
- 加入文字、文件引用及放入终端后清空草稿，都可在当前草稿框中撤销和重做。切换终端不会把另一个终端的撤销内容带过来。
- **加入文件或图片引用** 将路径追加到提示词。SSH 场景先上传到项目的 `.edgeterm-attachments/`，上传成功后才加入远端路径，进度在传输中心显示。
- 发送面板明确区分 **命令 / Agent 提示词**；折叠栏的“新建命令”和已保存命令编辑入口会打开命令输入框，两种模式分别保留草稿。
- 兼容面板提供 Pi / OpenCode 的安装检查、Pi 退出回放设置与终端诊断。提示词和选区功能不受这两个工具的选择器限制。会话历史与恢复继续使用各 Agent 自身的功能。

## 终端与文件面板

- 对超长自动折行输出限制语义着色扫描范围，避免一次刷新遍历整段回滚历史；不丢弃终端输出。
- 停靠的 Filer 使用紧凑列表和统一操作菜单，路径栏可以直接切换为输入框。双栏文件浏览器继续使用原有表格。
- 侧栏与停靠面板分隔条统一提供拖动预览和尺寸读数，双击恢复默认尺寸。
- 修复输入行选区在第一次删除或替换后无法继续编辑的问题，宽字符和 emoji 按字符处理。

## 安装与数据保留

安装版下载 `EdgeTerm_1.7.0_x64-setup.exe`，从菜单退出旧程序后安装到原位置。便携版下载 `EdgeTerm_1.7.0_x64-portable.zip`，升级时保留原有 `data` 目录，不要用空目录覆盖。便携模式密码只在当前进程会话内保存。

本分支继续手动下载更新，不后台检查或自动安装更新。发布页同时提供独立诊断包和 `SHA256SUMS.txt`。程序与安装器没有 Windows 数字签名；校验和用于核对文件完整性。

## 验证范围与限制

实际 Codex 0.166.0 / Windows WebView2 / ConPTY 已验证普通拖选、Shift 拖选、移动鼠标后高亮保留、引用撤销与重做，以及新建命令入口。该验收使用隔离配置和本地固定回复，没有使用用户会话或真实模型请求。其他 Agent 的具体版本、真实 SSH 和安装器升级未据此视为通过。

普通拖选引用的是可见屏幕文字。拖选时跨屏滚动、窗口尺寸或选中行文字发生变化，需要重新选择。文件引用不等同于图片二进制附件；远端上传文件会留在项目目录。

“需关注”仍根据终端活动推断，输出暂停不能证明 Agent 已完成任务。Agent 之间自动通信未在本版实现。构建、完整测试结果与附件校验记录见[发布索引](releases.zh-CN.md)。
