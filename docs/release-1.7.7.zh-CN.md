# EdgeTerm 1.7.7

相对上一个公开版本 **1.7.6**，本版包含其后合入 `main` 的全部 126 个提交（84 个修复、7 个新功能、4 个性能改动）。发行包面向 Windows x64，沿用原应用标识、配置目录和凭据存储。

## 用拖拽移动文件

- 在 Filer 里把一行拖到**文件夹行**上松手即可移动；拖动**多个已选行**时整组一起移动。
- 也可以拖到**路径栏的面包屑**上，把文件移动到上一级或更上层目录。
- 目标里已有同名文件时**整体拒绝**并说明是哪个名字，不会覆盖。
- 在大小写不敏感的本地卷上，`A.TXT` 与 `a.txt` 视为同一个名字；远端会话仍区分大小写。
- 拖动经过面板自己的标题栏、页脚或行间空隙不会中断；离开面板才交给系统做外部拖放。

## 文件管理器修复

- **拖回文件自己所在的文件夹不再报“已存在”**：此前会弹出一条冲突提示，尽管什么都没做。
- **大小写同名的文件不再被静默覆盖**：Windows 上把 `a.txt` 移进已有 `A.TXT` 的文件夹，此前会真的替换那份文件；现在直接拒绝。
- 面板正在执行其他操作时，拖拽不会被当成移动。
- 路径栏不再要求分隔符与当前会话一致（例如地址栏输入的 `C:/dir`）。

## 编辑器

- 本地 Windows 路径下的 `Dockerfile`、`Makefile` 等按文件名识别的语言不再退化成纯文本。

## 配置与数据安全

- 配置、导出与 Sender 命令的写盘都走**临时文件后改名**；导出文件**仅所有者可读**，半途失败不会替换上一个导出。
- **导入前备份**被替换的内容；写入失败会**回滚**。
- 同一导入文件**再导入一次不再重复**条目；缺 id 的导入条目沿用同一条目的 id。
- 导入会套用**跳板机规则**；导入的配置**不能削弱**粘贴保护；已保存的密码不会跟随导入串到另一个端点。
- 无法解析的配套配置文件会被**移到一边**，不会被覆盖或删除。
- 工作区快照读取失败或未被使用时**保留**并说明；布局写不进去、标签不会被保存时也会明说。

## 网络与隧道

- 一个异常的 SOCKS5 客户端不再把整条隧道标记为失败。
- 隧道失败会写日志，并显示在打开隧道列表的按钮上。
- 已结束的隧道记录会为新隧道腾位置。
- 关闭缓慢时会说明实际留下了什么。

## 性能

- 拖动改变窗格大小时，终端尺寸协商**每个拖动区间只发一次**，不再每帧都发 IPC。实测（`src/resizeCoalescer.test.ts`，假计时器）：一次拖动产生的 60 次尺寸上报从 **60 次发送降到 2 次**。
- 保存配置与写入命令历史改到运行时线程，不再占用 WebView 主线程；此项**没有做桌面端测量**。
- 标签列表不再持有每个会话的终端网格；行号槽只重绘本帧变化的行。

## 已知边界

- 安装包与程序**未签名**，首次运行会有系统警告。
- 未做安装后的桌面端冒烟测试；自动测试跑在 Chromium 上，不是 WebView2。
- 只发布 Windows x64；没有自动更新，也不检查上游更新源。
- 上述性能条目中，除尺寸协商那一项，其余都没有桌面端测量数据。
