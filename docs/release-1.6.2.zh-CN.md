# EdgeTerm 1.6.2

本分支相对上一个公开版本 **1.6.1** 的更新，面向 Windows x64，继续手动下载和安装。已有安装版沿用应用标识 `com.edgeterm.desktop`、配置目录和凭据存储，本版本没有数据格式迁移。

## Filer 停靠面板改为列表

- **更少的层，更多的名字**：停靠的 Filer 不再是一张塞进 300px 的三列表格。标题栏（36px）保留面板身份、上传/下载与一个 `…` 菜单，路径栏（36px）保留面包屑与编辑入口，列表从第三层直接开始——首行数据之前从 148px 降到 72px，名称列在默认宽度下从约 90–100px 增到约 136px（隐藏大小时约 194px）。
- **路径只出现一次**：面包屑常显；点路径栏的空白处或铅笔图标，同一位置变成输入框（Enter 应用、Esc 还原）。
- **元数据收成一簇**：大小（可选）和时间右对齐地跟在名称后，单一墨色；时间只保留两种形态（本年内 `MM-DD HH:mm`、跨年 `YYYY-MM-DD`），无法确定时留空，完整时间戳在行 tooltip 里说明。
- **一个视图菜单**：新建文件/文件夹、上传文件/文件夹、下载、重命名、删除、刷新、定位到终端目录、跟随终端、显示大小、三种排序（当前键带 ↑/↓，再点切换方向）都在 `…` 里；不再有表头、列宽把手、横向滚动或“显示列”文字按钮。
- **旧列宽偏好被忽略**：`edgeterm.filerColumns` 仍保留以便旧设置导入与“恢复默认”，但列表没有列宽可恢复。

## 拖拽与尺寸

- **侧栏外缘**：保留预览线，并新增拖动时的宽度读数；双击回到默认宽度（左 220 / 右 300），边界由同一套 clamp 决定。
- **面板间分隔条**：与侧栏外缘统一为预览线 + 松手落位，双击回到均分；分栏比例按 dock 记住（`edgeterm.dockSplits`），重启后仍在。
- **拖动引导线**：悬停/拖动时的强调线从 3px 改为 4px，水平分隔条也有同样的预览。

## 输入行选区编辑：可以连续删除

- **第一次之后也有效**：删除选区后，shell 光标现在走回编辑前的位置，因此紧随其后的选区仍在光标左侧，可以继续选中删除；1.6.1 里第二次选择会越过光标而被拒绝，只发出一次单字符 Delete。
- **替换、粘贴、输入法同样归位**：键入的字符、粘贴文本、输入法上屏的文本落地之后，光标再走回原处（替换路径的归位排在文本之后发出），所以连续替换后仍能按选区编辑。
- **按字符计数**：宽字符与 emoji 各算一个光标步长（emoji 不再按两个 UTF-16 单元计数），选区边界落在宽字符尾半格时仍按整个字符处理。
- **不可编辑的场景保持 1.6.1 的行为**：选区在输出内容上、命令运行中、会话已断开、程序接管鼠标或使用全屏界面、选区越过光标（zsh 自动建议的灰色文字不是输入）、选区起始于提示符内部——按键仍按原来的方式送达。

## 安装与数据保留

安装版用户下载 `EdgeTerm_1.6.2_x64-setup.exe`，退出应用后安装到原位置，无需先卸载。便携版使用程序旁的 `data` 文件夹；升级便携版时保留已有 `data`，不要用空目录覆盖它。便携模式的密码只在当前进程会话内保存。

本分支不后台检查或自动安装更新；应用中的“下载与更新…”打开本分支发布页。可用发布页的 `SHA256SUMS.txt` 核对下载的附件。安装器与程序未进行 Windows 数字签名；校验和用于核对文件完整性，不能代替发布者签名验证。独立诊断包用于从应用外部收集窗口无响应的证据，不会自动上传。

## 验证与边界

本版在本机真实 Edge 与模拟 IPC 上验证：前端单元测试 112 文件 / 1046 项、浏览器用例 29 文件 / 137 项、451 项 Rust 测试通过（28 项按配置跳过）；TypeScript、Biome 格式、lint 与前端生产构建通过；安装包与附件经 `release:package --check` 逐个核对 SHA-256。开发版窗口在真实 WebView2 上启动并完成首帧，但安装包本身没有在作者机器上执行安装升级验收；选区修复的自动化用例模拟 shell 重绘，尚未在真实 pwsh / SSH bash 会话中人工复验。

## 已知限制

- 双栏（SFTP/FTP）文件浏览器的表格列系统本版未改：列宽/显示隐藏/双击适配按文档中的后续计划单独处理。
- 本版对 Filer 与选区编辑的验收在真实 Chromium 与模拟 IPC 上完成；真实 Tauri/WebView2 窗口、真实 SSH 会话（本地 pwsh 与远端 bash）以及 zsh/fish 自动建议场景仍需实机复验，结论与边界见发布索引。
- 旧版拖过的 Filer 列宽不会迁移到新列表（列表没有列宽）。
