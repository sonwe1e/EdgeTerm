EdgeTerm

From cloud to edge — one terminal for everything 从云端到边缘，一个终端连接一切

Terminal, SSH, FTP and serial in one native client, built with Rust + Tauri v2 and a React + xterm.js frontend. The entire SSH stack is pure Rust (russh) — no libssh2, no OpenSSL, no pkg-config. 终端、SSH、FTP 与串口集于一个原生客户端，基于 Rust + Tauri v2 与 React + xterm.js 前端构建。SSH 协议栈由纯 Rust（russh）实现，不依赖 libssh2、OpenSSL 或 pkg-config。

Before you install: Windows needs the Microsoft WebView2 runtime, which ships with Windows 11 and with a current Microsoft Edge on Windows 10. Because the installers are not code-signed yet, Windows SmartScreen and macOS Gatekeeper will warn on first launch — the tutorial shows the two clicks to continue. 安装前请知悉：Windows 需要 Microsoft WebView2 运行时（Windows 11 自带；Windows 10 随较新的 Microsoft Edge 提供）。安装包暂未做代码签名，首次启动时 Windows SmartScreen 与 macOS Gatekeeper 会提示风险；教程中写明了继续的两步操作。

After it opens: you get an empty workspace. Press Alt+N (or the New Session button), choose Local Shell for a terminal on this machine, or fill in host and user for SSH. The first successful connection is a shell prompt you can type into — nothing needs an account. 打开之后：会看到一个空工作区。按 Alt+N（或点 New Session），选 Local Shell 得到本机终端；SSH 则填写主机与用户名。首次成功的标志是可以输入命令的 shell 提示符——全程不需要账号。

Your servers stay yours服务器信息留在本机

No telemetry. Saved passwords never enter the page or sessions.json: they are sealed in credentials.json, with the key held by the OS credential store. This fork does not check for updates automatically. Help → Downloads and Updates opens this fork's releases when requested. 没有遥测。保存的密码不会进入页面或 sessions.json：它们被封存在 credentials.json，密钥由系统凭据库保管。本分支不自动检查更新；“帮助 → 下载与更新”在用户操作后打开本分支发布页。
