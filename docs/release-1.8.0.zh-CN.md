# EdgeTerm 1.8.0

本版面向 Windows x64。相对上一个公开版本 1.7.7，主要变化集中在终端会话、命令发送、文件导航与 Git 工作区。

- **多会话操作**。在「会话 → 广播输入」打开同步输入，可以把按键同时发给多个已连接的终端。底部状态栏可查看广播范围，结束后可随时关闭。Sender 适合先写好命令，再一次发送给当前或多个会话。Windows 本地 cmd 的新命令默认使用 CRLF，已保存命令沿用各自的行尾。
- **深目录导航**。文件面板优先显示路径末尾，进入深层文件夹或把面板拖窄后，仍能看到当前目录。向左滚动可点击前面的上级目录，点铅笔可查看和编辑完整路径。
- **终端回看与分屏**。可以从「视图」跳到上一条命令、shell 报告失败的命令，或带错误和警告关键词的输出行。分屏时可临时放大当前窗格，再次切换即可恢复。
- **会话查找与连接**。会话列表支持按主机、用户、端口和分组筛选。命令面板可直接连接输入的主机，快速连接支持 SSH 链接和带方括号的 IPv6 地址。
- **Git 工作区**。支持在本地和 SSH 工作区查看变更与差异、暂存文件和提交。菜单、命令面板、日志查看器和 Sender 已保存命令列表的键盘操作也有改进。

## 下载与升级

常规安装选择 `EdgeTerm_1.8.0_x64-setup.exe`。便携用户选择 `EdgeTerm_1.8.0_x64-portable.zip`，升级时保留原有的 `data` 目录。下载后可运行 `Get-FileHash <文件名> -Algorithm SHA256`，与同页的 `SHA256SUMS.txt` 比对。诊断工具另附在 `EdgeTerm_1.8.0_windows-diagnostics.zip` 中。

本版采用手动下载，程序和安装包均未做 Windows 代码签名。
