# EdgeTerm 1.6.0

本分支相对上一个公开版本 **1.5.1** 的更新，面向 Windows x64，继续手动下载和安装。已有安装版沿用应用标识 `com.edgeterm.desktop`、配置目录和凭据存储，本版本没有数据格式迁移。

## 终端与文件、目录、远程资源的直连

- **报错里的文件路径可直接打开**：终端输出中的 `File "/path/model.py", line 238`、`/path/train.py:120`、`/path/train.py:120:8` 与相对路径，按住 Ctrl（macOS 为 ⌘）点击即可用该会话自己的文件系统打开内置编辑器并定位到行。相对路径按"该行输出时终端所在目录"解析——滚动历史里先前的报错在用户切到别的目录后仍指向正确的文件；解析不到归属时回退到会话当前目录，仍失败才提示。路径以空格、引号或括号包裹、grep 风格 `path:line:text`、`--flag=/path` 均可识别；URL、Windows 形态路径、无扩展名的 `a:b`、超出范围的行号不生成链接。悬停只做文本解析，不访问服务器；文件在点击时才读取，读取失败在状态栏说明原因而不打开空编辑器。
- **Filer 可跟随终端目录**：目录栏新增三态按钮（关闭 / 跟随中 / 已暂停），默认关闭，按会话各自记忆、只在本次运行内有效。开启后终端 `cd` 到哪，Filer 就跟到哪；手动进入其他目录会自动暂停，点击后重新同步；连续快速 `cd` 只显示最后一个目录（400 毫秒合并）。Shell 不报告目录时首次同步会向服务器询问一次，之后不再猜测；本地 Shell 里手工 `ssh` 到另一台机器时会暂停并说明原因，不把远处的路径当成本机路径。
- **终端里的本机地址经 SSH 转发打开**：SSH 终端输出的 `http://localhost:6006/` 之类地址，Ctrl+点击会为它建立临时本地转发（`127.0.0.1` 随机端口 → 服务器自己的端口），再在系统浏览器打开；同一服务器同一目标只建一条，并发点击共享同一次建链；公网地址仍按浏览器直接打开。转发属于该会话，切标签不会中断，会话关闭时清理。
- **远程 HTML 实验报告可在浏览器预览**：在远程 Filer 中右键 `.html` 文件选择"在浏览器中预览"，EdgeTerm 启动一个只监听本机的只读 HTTP 服务，通过该会话的 SFTP 按需流式读取报告目录，因此报告里的相对 `charts.js`、`data.json`、`assets/*.png` 都能在真实浏览器里加载；训练过程中改写 `data.json` 后刷新即可看到新结果。服务只允许 GET/HEAD，地址带一次性随机令牌，仅接受本机 Host，路径与符号链接都不能越出报告所在目录，单文件上限 512 MiB，默认 `no-store` 不缓存，支持单段 Range。同一报告重复打开复用同一预览，右键可停止，会话关闭时也会释放端口。首版只支持报告同目录下的相对资源，`/assets/...` 这类根路径引用不在范围内。

## 鼠标定位

- Alt+点击把 Shell 的光标移到点击位置（由 xterm 以方向键模拟，宽字符按格计算，自动换行与 CJK 均可用）；程序自己接管鼠标时（OpenCode、Vim、tmux 等），点击作为带修饰键的鼠标事件交给程序，Alt+点击不会再被终端占用；把视口滚回历史后点击不会改写前台程序的输入。本轮显式声明该行为并补充真实浏览器回归，没有重写鼠标坐标逻辑。

## 安装与数据保留

安装版用户下载 `EdgeTerm_1.6.0_x64-setup.exe`，退出应用后安装到原位置，无需先卸载。便携版使用程序旁的 `data` 文件夹；升级便携版时保留已有 `data`，不要用空目录覆盖它。便携模式的密码只在当前进程会话内保存。

本分支不后台检查或自动安装更新；应用中的“下载与更新…”打开本分支发布页。可用发布页的 `SHA256SUMS.txt` 核对下载的附件。安装器与程序未进行 Windows 数字签名；校验和用于核对文件完整性，不能代替发布者签名验证。独立诊断包用于从应用外部收集窗口无响应的证据，不会自动上传。

## 验证边界

Windows x64 本地检查：110 个前端单元测试文件 / 1026 项、29 个浏览器测试文件 / 156 项（真实 Edge，含 Alt+点击 4 项、Filer 跟随与文件跳转各 1 项端到端）、451 项 Rust 测试通过，另有 28 项 Rust 测试按配置跳过。另有一条针对真实 sshd 的远程预览验收用例（本机 WSL Ubuntu sshd，`127.0.0.1:2222`）通过：相对 JS/CSS/PNG 加载、`data.json` 改写后刷新可见、256 KiB 分块流式、Range 206、HEAD、`../` 与 `%2e%2e` 被拒、符号链接越界被拒、绝对路径被拒、错误令牌被拒、外部 Host 被拒、POST 405、停止后端口释放。TypeScript、Biome 格式与 lint、前端生产构建、Rust 格式、绑定一致性检查（97/102 命令）均通过；提交历史逐提交通过提交规范与类型检查。lint 保留生成绑定中的两条既有 `any` 警告。

浏览器回归使用模拟 IPC；Rust 侧回环用例使用本地目录源。这些检查不能替代真实 Tauri/WebView2 窗口内的鼠标定位、Ctrl+点击、跟随按钮与右键预览菜单，不能替代真实 OpenCode / Vim / tmux 的鼠标行为、中文输入法组合态、系统浏览器实际打开、应用窗口内的隧道端到端、高输出下的链接识别与跟随性能、并发与上限边界，也没有覆盖 macOS/Linux 桌面环境与已有用户数据的安装升级。具体构建来源、附件校验和与验证结果见[发布索引](releases.zh-CN.md)。
