# EdgeTerm 1.5.1

本分支相对上一个公开版本 **1.5.0** 的更新，面向 Windows x64，继续手动下载和安装。已有安装版沿用应用标识 `com.edgeterm.desktop`、配置目录和凭据存储，本版本没有数据格式迁移。

## 远程编辑与保存

- 在按协议拒绝覆盖已有目标的 SFTP 服务器（部分 Windows OpenSSH、NAS 固件等）上，保存已打开的文件不再以“无法替换”失败。替换按顺序尝试：服务器声明的 `posix-rename` 扩展（原子覆盖）→ 普通 `RENAME` → 先把原文件移开再替换、失败时把备份移回 → 最后才原位重写并回读校验。全部失败时的错误信息说明服务器上每个文件的实际位置，不误报仍存在的备份。
- 重新读取不再无条件覆盖编辑内容：工具栏“重新加载”在缓冲区有未保存修改时先弹确认；读取在途时的新键入不会被服务器副本覆盖——重新加载会取消并提示，缓冲区保留新输入并立即写入草稿。
- 打开文件时如果在读取完成前就开始输入，输入内容会保留，服务器副本作为已保存基线，不再被加载结果覆盖。

## 运行日志

- 运行控制台中 Python traceback 的帧行（`File "…", line N`）现在可以点击，直接打开对应的远程文件并定位到行。识别有边界：只识别这种帧格式；`<stdin>`/`<frozen …>` 等虚拟路径和 Windows 盘符路径不生成链接；相对路径按项目源码根解析，不指向隔离快照目录；只有日志尾部 200 行参与识别；未连接服务器时保持纯文本。

## 连接

- 慢链路上的 SFTP 不再超时失败：终端能连上但文件面板打不开的服务器（子系统确认或版本交换超过原预算），现在分别获得 15 秒子系统等待和 25 秒单请求上限。拒绝子系统的服务器仍会立即报错。

## 安装与数据保留

安装版用户下载 `EdgeTerm_1.5.1_x64-setup.exe`，退出应用后安装到原位置，无需先卸载。便携版使用程序旁的 `data` 文件夹；升级便携版时保留已有 `data`，不要用空目录覆盖它。便携模式的密码只在当前进程会话内保存。

本分支不后台检查或自动安装更新；应用中的“下载与更新…”打开本分支发布页。可用发布页的 `SHA256SUMS.txt` 核对下载的附件。安装器与程序未进行 Windows 数字签名；校验和用于核对文件完整性，不能代替发布者签名验证。独立诊断包用于从应用外部收集窗口无响应的证据，不会自动上传。

## 验证边界

Windows x64 本地检查：107 个前端单元测试文件 / 919 项、31 个浏览器测试文件 / 152 项、459 项 Rust 测试通过；另有 27 项 Rust 测试按配置跳过。TypeScript、Biome 格式、lint、Rust 格式和 Rust/前端绑定一致性检查通过；`a9df679..` 之后的 5 个提交逐个通过提交规范与类型检查。lint 保留生成绑定中的两条既有 `any` 警告。

浏览器回归使用模拟 IPC；保存替换策略的回归使用内存 wire 协议夹具，不依赖真实服务器。这些检查不能替代真实 SSH/SFTP 服务器（尤其是拒绝覆盖的实机）、活跃模型流式输出、已有用户数据的安装升级、其他显卡组合或 macOS/Linux 桌面环境的验收。具体构建来源、附件校验和与验证结果见[发布索引](releases.zh-CN.md)。
