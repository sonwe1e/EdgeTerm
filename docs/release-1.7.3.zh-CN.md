# EdgeTerm 1.7.3

相对上一个公开版本 **1.7.2**，本版增加实验性的无缝冷历史（默认关闭），改进 oh-my-pi 会话识别与 Agent 重绘时的侧栏稳定性，并修正显示设置中实验开关的保存时机。发行包面向 Windows x64，沿用原应用标识、配置目录和凭据存储。

## 无缝冷历史（实验，默认关闭）

- 终端超出回滚范围的行不再直接丢弃：它们被序列化（保留 SGR 颜色属性）转入内存压缩存储；向上滚动到缓冲顶部时自动接回原位置，终端因此可以回看远早于回滚窗口的历史。
- 在「显示设置 → 无缝冷历史」开启；压缩存储上限为每会话 64 MB、全局 256 MB。超出回滚的行先转入内存缓冲，达到阈值后按设置溢写。
- 查找框会统计命中里来自冷历史的行数，与常规命中分开显示。
- **实验边界**：64/256 MB 上限仅覆盖压缩存储；回填到终端的行会额外占用内存。超长折行在冷热边界可能丢字。滚顶物化与搜索的修正仍在 Draft PR #2 中验证，未随本版发布；已知内存增长问题见该 PR 的阻断记录。
- 该功能默认关闭；没有开启过的用户升级后行为与 1.7.2 一致。

## Agent 终端

- 识别交互式 oh-my-pi（`omp`）会话：`omp` 与 `omp launch` 进入 Agent 活动跟踪；headless（`-p`/`--print`/`--mode`）、导出及 `stats`/`config`/`models` 等约六十个管理子命令不误判为编码会话。
- 侧栏（时间戳 + 行号）改为固定轨道宽度：交替屏程序（vim、tmux）与在常规缓冲重绘的 Agent TUI（oh-my-pi、OpenCode）隐藏误导性行号/时间戳内容，但保留占位宽度。终端不再因侧栏内容清空而收缩并向运行中的 TUI 反复发送 resize。

## 显示设置

- 「无缝冷历史」开关改为与其他显示设置一致：点击「应用」才保存；「取消」与「恢复默认」不再直接写入偏好，避免误开启实验功能。
- 开关提示文案标示实验状态与上述内存/折行风险。

## 安装与数据保留

安装版下载 `EdgeTerm_1.7.3_x64-setup.exe`，从菜单退出旧程序后安装到原位置。便携版下载 `EdgeTerm_1.7.3_x64-portable.zip`；升级时保留原有 `data` 目录，不要用新包的空目录覆盖。

历史记录中存在 2026-11-05 仅供本机使用的 1.7.3 本地安装包（Pi 滚轮修复，未发布）；本公开版本内容与哈希均不同，请以本发布页附件及 `SHA256SUMS.txt` 为准。本分支继续手动下载更新，程序与安装器没有 Windows 数字签名；校验和用于核对文件完整性。

## 验证范围

oh-my-pi 识别与侧栏固定宽度在真实 Windows 11 / WebView2 / Tauri 便携版上完成 P0 级真机验收（本地 Shell 与 SSH、OpenCode、Pi、Vim/tmux、中文 IME 组合路径、4 并行 SSH 标签、窗口调整与搜索），配套的仓库原生门禁与单元/浏览器回归全部通过；A2 冷历史按用户决策保持默认关闭，其开启路径由单元测试覆盖，真机仅验证了「保持关闭、Cancel 不开启」。完整测试边界与逐项记录见 [1.7.2 稳定体验验收卡](team/edge-term-1.7.2-stable-acceptance.md)与[发布索引](releases.zh-CN.md)。
