# EdgeTerm 1.7.2

相对上一个公开版本 **1.7.0**，本版增加工作区恢复，并改进 OpenCode 状态显示和 Pi 全屏滚动。发行包面向 Windows x64，沿用原应用标识、配置目录和凭据存储。

## 重启后恢复工作区

- 启动时重新打开上次的会话标签，恢复标签顺序、选中标签和分屏布局，并分别记住终端、Filer 和 FTP/SFTP 双栏目录。各标签独立重连；连接失败的标签保留，可供重试。
- 工作区从本版开始记录，首次从旧版升级时无法恢复旧版没有保存的标签。重新连接会启动新的会话，不会续跑退出前的命令或 Agent 任务。
- 工作区记录保存在本机，包含必要的会话配置和路径，不保存密码、私钥口令或终端输出。便携模式重启后仍需重新输入密码和口令。
- Windows 交互式 cmd / PowerShell 支持报告当前目录。SSH 目录恢复依赖远端的目录报告或 Linux `/proc`；非 POSIX SSH、自定义启动脚本、WSL 或无法报告目录的环境不保证恢复终端目录。已删除的目录会回退到主目录。

## Agent 终端兼容

- OpenCode 2.2.5 可通过其终端状态报告控制标签活动状态：空闲时停止活动动画，输入草稿和空闲重绘不会重新触发动画；工作、等待和结束状态继续通过已有标签提示呈现。没有明确状态报告的工具仍使用终端活动推断。
- 修复 SSH 命令回显晚于 Enter 时遗漏 OpenCode 状态的问题；退出后普通命令仍按原方式显示活动状态。
- 已识别的 Pi 全屏会话在鼠标上报缺失时，将滚轮产生的方向键改为翻页键，避免滚动对话时切换输入历史。正常鼠标报告、键盘方向键和其他程序保持原行为。

## 安装与数据保留

安装版下载 `EdgeTerm_1.7.2_x64-setup.exe`，从菜单退出旧程序后安装到原位置。便携版下载 `EdgeTerm_1.7.2_x64-portable.zip`；升级时保留原有 `data` 目录，不要用新包的空目录覆盖。

先前仅供本机使用的 1.7.2 安装包不含后续 Pi 滚轮修复；本次公开版包含该修复。请以本发布页的附件及 `SHA256SUMS.txt` 为准。本分支继续手动下载更新，程序与安装器没有 Windows 数字签名；校验和用于核对文件完整性。

## 验证范围

工作区恢复的浏览器测试使用真实 Edge 与模拟 IPC；Windows ConPTY 和本机 WSL OpenSSH 的目录报告另有实际会话测试。OpenCode 2.2.5 和 Pi 1.5.0 的兼容修复曾使用本机 SSH、Windows WebView2 和隔离测试数据验证；Pi 的鼠标模式缺失由测试人为注入。没有连接用户远端主机或调用真实模型，其他 Agent/Pi 版本及用户环境不据此视为通过。构建结果与完整测试边界见[发布索引](releases.zh-CN.md)。
