# EdgeTerm 1.6.1

本分支相对上一个公开版本 **1.6.0** 的更新，面向 Windows x64，继续手动下载和安装。已有安装版沿用应用标识 `com.edgeterm.desktop`、配置目录和凭据存储，本版本没有数据格式迁移。

## 输入行选区编辑

- **选中即可直接编辑**：在还没回车的命令输入行上，用鼠标选中一段文字后——按 Delete 或 Backspace 删除选中段；直接键入字符（含 Shift 大写与符号）替换选中段；粘贴替换选中段；中文输入法在选中状态下开始组字，上屏文本即替换选中段；复制行为不变。不再需要用方向键把光标挪到出错的位置。
- **与 shell 协作而不是绕过它**：编辑以 shell 自己的按键序列（方向键左移、前向删除，按字符计数）送达，本地 pwsh 与 SSH 会话（bash、zsh 等）行为一致；宽字符（中文）按一个字符计数，自动换行的长命令行可跨行选中；选区边界落在宽字符中间时按整字符处理。
- **不可编辑的场景保持原行为**：选区在输出内容上、命令运行中、会话已断开、程序接管鼠标或使用全屏界面、选区越过光标（zsh 自动建议的灰色文字不是输入）、选区起始于提示符内部——这些情况下按键仍按原来的方式逐字节送达，不做任何拦截。

## 菜单栏修复

- 按住 Alt 点击终端（把光标移到点击处、Alt+拖拽块选择）后，菜单栏不再把这次 Alt 当作“单独按下 Alt”而弹出下拉菜单；单独按 Alt 打开菜单栏、Alt+点击移动光标、Alt+Delete 等组合键行为不变。此前的行为与 shell 类型无关（pwsh、bash 均可复现），本修复同样适用于全部会话。

## 安装与数据保留

安装版用户下载 `EdgeTerm_1.6.1_x64-setup.exe`，退出应用后安装到原位置，无需先卸载。便携版使用程序旁的 `data` 文件夹；升级便携版时保留已有 `data`，不要用空目录覆盖它。便携模式的密码只在当前进程会话内保存。

本分支不后台检查或自动安装更新；应用中的“下载与更新…”打开本分支发布页。可用发布页的 `SHA256SUMS.txt` 核对下载的附件。安装器与程序未进行 Windows 数字签名；校验和用于核对文件完整性，不能代替发布者签名验证。独立诊断包用于从应用外部收集窗口无响应的证据，不会自动上传。

## 验证边界

Windows x64 本地检查：111 个前端单元测试文件 / 1051 项、30 个浏览器测试文件 / 160 项（真实 Edge，含 Alt+点击 5 项、终端输入 5 项、输入行选区编辑 3 项端到端指针用例）、451 项 Rust 测试通过、28 项按配置跳过；TypeScript、Biome 格式与 lint、前端生产构建通过。菜单栏修复的回归用例先在旧实现上运行并失败（Alt+点击后下拉确实弹出），修复后通过。Rust 全量首跑曾有一条远程转发清理用例在并行负载下断言时序状态失败，单独重跑与全量重跑均通过；本版本未改动 Rust 代码。

浏览器回归使用模拟 IPC；不能替代真实 Tauri/WebView2 窗口内的 Alt+点击、选区删除/替换与中文输入法组合态的实际体验，未覆盖 zsh 自动建议、OpenCode/Vim/tmux 等程序的选区场景，也未在已有用户安装上执行安装器升级。具体构建来源、附件校验和与验证结果见[发布索引](releases.zh-CN.md)。
