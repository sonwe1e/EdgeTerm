# EdgeTerm 1.4.0

本分支相对上一个公开版本 **1.3.0** 的更新。面向 Windows x64，继续手动下载安装；既有安装版沿用原应用标识 `com.edgeterm.desktop`、配置目录和凭据存储，没有数据格式迁移。

## 内置文件编辑器

- 文件栏的单文件菜单新增“在内置编辑器中编辑”，不需要先建立项目：本地 UTF-8 文本和已连接 SSH/SFTP 会话上的文本都能直接打开。单文件上限 4 MiB，拒绝二进制内容。
- 编辑器标题区显示目标路径和服务器身份；本地目标为“保存到本地文件”，远程目标为“保存到服务器”，写回原会话对应的服务器。SSH/SFTP 沿用工作台的编码、BOM、换行和 SHA-256 冲突检查。
- 保存冲突或写入无法确认时保留草稿并提示；保存或重新读取期间继续输入的内容仍标为未保存，不会被读取结果覆盖。关闭、重新读取和退出程序前会确认未保存内容。
- 外部“打开 / 打开方式”仍然可用；FTP 的内置远程编辑尚未提供，继续使用外部编辑。
- 临时编辑内容只保存在当前进程内存中，不进入项目草稿恢复列表；程序崩溃后无法恢复。本地保存先写同目录临时文件再替换，并与外部进程之间存在很短的检查-替换竞态窗口。

## 传输队列

- 上传只在选择文件和确认覆盖期间占用上传入口，提交后由后台队列继续传输；完成后只刷新仍在浏览的同一会话、同一目录，不清除选择、不改变路径，也不覆盖其他错误。过期目录响应和过期选择结果不会落入新位置，取消不按失败提示。
- 队列显示服务器、协议、方向、第一组源/目标路径和选择项数，并显示连接、扫描、续传校验、传输、提交等阶段；总量未确定时使用不定进度，100% 字节不代表文件已提交完成。
- 并行文件仍在传输数据时，任务阶段回到“传输中”，不再整任务停留在“提交中”。
- 队列可以固定在应用底部，继续操作文件栏不会关闭；取消固定恢复浮层行为。固定状态只属于本次窗口布局，不新增跨启动偏好。
- 设置中的传输入口直接展开传输参数并聚焦摘要。

## 连接表单

- 连接失败后的重试保留在同一标签内：先保存连接设置再连接，失败时显示“已保存”提示、排查说明和技术细节，不重复新建配置或标签。
- 新建连接默认折叠名称/颜色/分组，编辑现有连接时展开；本地、串口和远程协议的新建焦点分别落在各自需要的字段上。
- 端口转发、跳板机和终端参数收进折叠的“高级”区。

## 工作台

- 工作台自身宽度不足 900px 时在项目、文件和编辑器之间切换，区域保持挂载，文档状态保留；空编辑器提供项目文件入口。
- 更窄时运行栏换行，日志和运行详情上下排列并可滚动。
- 项目表单可以内联新增 SSH 服务器，保存后自动选中并保留已填写的项目名称和路径；点击背景不再关闭表单，改动未保存时关闭会确认。

## 终端

- 行号槽在重绘和调整宽度后保留各行原有时间，旧输出不再继承最新时间。

## 文件传输引擎

- 同一任务的多个文件共享请求窗口，短文件不再占住额度让长文件等待；小文件下载复用已读样本，减少一次 OPEN/READ 往返。
- 这些结果是请求计数与窗口占用的改善，**不是**吞吐倍数，也不证明已达到 rclone 的速度。

## 安装与数据保留

已有安装版用户优先下载 `EdgeTerm_1.4.0_x64-setup.exe`，退出应用后安装到原位置，无需事先卸载或导出再导入配置。安装过程中保留应用数据；若选择卸载流程，不要勾选删除应用数据。

便携包使用同级 `data` 文件夹，适合需要独立配置的用户，不会自动显示安装版的配置。文件完整性可通过同一发布页的 `SHA256SUMS.txt` 核对。

随包提供的 `EdgeTerm_1.4.0_windows-diagnostics.zip` 是仓库内诊断脚本的独立副本，用于在窗口无响应时从应用外部取证；它不重启或终止应用，不截图、不读取终端内容、不自动上传。

## 验证边界

发布准备检查在 Windows x64 受限 runner 上运行：前端单元测试 105 个文件 / 900 项通过；浏览器回归（Playwright chromium）27 个文件 / 139 项通过；Rust 测试 449 项通过、27 项专用环境或基准测试保持跳过。TypeScript、Biome 格式检查、lint、Rust 格式检查和生产前端构建通过；`d7d9eaf` 之后的提交逐提交类型检查通过。

lint 保留生成绑定中的两条既有 `any` 警告；Rust 构建报告 4 条未使用代码警告（`Write`/`Ended`/`Failed` 变体、`require_session`、`posix_candidates`、`ServerRef::key`），均未阻断构建，相关文件不在本版本改动范围内。

浏览器用例使用模拟 IPC，传输引擎用例使用内存协议夹具：它们证明前端行为和请求窗口占用，不能代替真实 WebView2、真实 SSH/SFTP 服务器、真实吞吐或各显卡驱动的组合验收。FTP 内置编辑、程序崩溃恢复以及 macOS/Linux 桌面包都不在本次验证范围。ignored 项需要专用环境，不算通过。最终构建来源、附件校验和及发布核对结果见[发布索引](releases.zh-CN.md)。
