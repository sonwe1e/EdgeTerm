# EdgeTerm 1.7.6

相对上一个公开版本 **1.7.3**，本版包含其后的全部工作；1.7.4 与 1.7.5 只作为开发版本号存在，从未公开发行。发行包面向 Windows x64，沿用原应用标识、配置目录和凭据存储。

## 从上游 1.0.5–1.0.7 选择性移植

- **Sender 保留空行**：多行命令里的空行与纯空白行按原样发送，heredoc 与交互式程序需要的裸回车不再丢失；末尾换行按行终止符处理（上游 #115）。
- **查找框跟随活动窗格**：分屏时查找框落在当前活动窗格内，窄窗格里自动换行收缩，不再固定在中央区右上角。
- **会话分组右键“新建会话”**：按分组类型预填协议、端口和分组。
- **标签右键“保存会话…”**：把当前标签的连接设置存成 profile 并重绑到该标签，不重新拨号；改动在下次重连生效。
- **文件列表稳定排序**：大小或修改时间相同的条目按名称排序，刷新不再打乱行序。
- **取消传输立即收起进度条**：不再等待可能卡住的网络读返回。

处置明细（含未采纳的上游功能删除）见[上游移植记录](upstream-ports.zh-CN.md)。

## Filer

- 图片预览：受支持的远程与本地图片可在 Filer 内打开可缩放的近全屏预览；远程图片复用已缓存的 SFTP 通道，本地图片打开前预检。
- 只读日志查看器：有界读取远端日志，翻页与可见窗口对齐。
- 传输失败后的“重试”直接重跑原操作，不再只是刷新列表。

## 编辑器、输入法与草稿

- 拒绝不安全或不完整的可编辑文本读取，避免读到半截内容。
- 选区替换延迟到输入法提交之后执行。
- Filer 与 Sender 草稿里的输入法按键不再误触发。
- 并发的编辑动作不再互相覆盖草稿；编辑器的打开与确认按文件隔离。
- 字号输入在编辑结束后规范化，不再每个按键都触发终端重排。

## 菜单、标签与键盘

- 嵌套上下文菜单不再被父级滚动容器裁剪。
- 菜单打开时键盘焦点可见，滚动与键盘归属保持稳定。
- 窄标签栏中的提示操作改为紧凑排布。

## 会话与终端

- SSH 重连后重置残留的终端模式（鼠标上报、括号粘贴等），避免新连接沿用旧状态。
- 识别带环境变量前缀的 SSH shell 提示符。
- 取消中的会话工作在重连前退场。
- 后台传输未完成时，退出程序会先确认。
- Sender 广播只发送给已连接的终端。
