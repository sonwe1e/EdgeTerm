# EdgeTerm 1.3.0

本分支相对上一个公开版本 **1.2.8** 的更新。面向 Windows x64，继续手动下载安装；既有安装版沿用原应用标识、配置目录和凭据存储方式。

## 文件栏与拖动

- 文件栏的名称、大小、时间列可以分别调宽；双击列边界按内容适配，也可从文件夹菜单重置列宽。已有大小、时间列宽设置保持兼容。
- 拖动侧栏时逐帧调整布局，结束后保存尺寸；文件栏列宽拖动在松手时应用最后一帧。
- 补齐标签拖动中断时的状态和监听器清理，减少残留拖动状态。

## 终端显示与搜索

- 系统显示缩放变化后重新适配可见终端的行列数与行号间距；隐藏标签延后渲染器的缩放更新，再次显示时按最新比例更新。
- 移除侧栏调整路径上重复的终端尺寸监听；终端网格未变时跳过多余的非强制适配。
- 正则搜索移到可取消的工作线程，超时后可修改条件继续搜索；高亮仅处理可见区域，避免复杂表达式长时间占用页面主线程。
- 右键菜单的键盘操作不再误传给终端输入。

## 工作台与文件传输

- 修复项目搜索的请求生命周期，切换上下文或连续搜索时丢弃过期结果，并处理输入法组合输入。
- 快速打开的键盘选择会跟随滚动，结果变化后保持有效选中项。
- 调整工作台操作区在较窄空间和较大字号下的布局；主机详情可用键盘关闭并把焦点归还给触发按钮。
- 改善 FTP 服务器拒绝追加上传、同时重置被动数据连接时的回退处理；仅在确认不支持追加的响应后重新上传。

## 下载与诊断

- 应用内下载与更新入口指向本分支 `sonwe1e/EdgeTerm`，不再使用上游自动更新源。本版本没有后台自动升级。
- 附带独立的 Windows 卡死取证工具：可从应用外部收集实际程序/WebView2/驱动版本、DPI、原生消息响应及限定进程采样，不截图、不读取终端内容、不自动上传。

## 安装与数据保留

已有安装版用户优先下载 `EdgeTerm_1.3.0_x64-setup.exe`，退出应用后安装到原位置，无需事先卸载或导出再导入配置。安装过程中保留应用数据；若选择了卸载流程，不勾选删除应用数据。

便携包使用同级 `data` 文件夹，适合需要独立配置的用户，不会自动显示安装版的配置。文件完整性可通过同一发布页的 `SHA256SUMS.txt` 核对。

## 验证边界

Windows 11 系统显示缩放与侧栏拖动问题的报告者，在安装本轮修复构建后反馈“好像没什么问题了”。这是该机器的用户复测反馈；尚未获得其阻塞堆栈、精确驱动版本或长期重复测量，不扩大为所有硬件上的卡死根因已确认或全部消除。

浏览器夹具证明前端行为，不能代替真实 WebView2、系统 DPI 消息和各显卡驱动的组合验收。既有用户资料上的完整卸载/重装流程未作为自动化测试运行。最终构建来源、附件校验和及发布核对结果见[发布索引](releases.zh-CN.md)。未发布 macOS/Linux 安装包，也未启用签名自动更新。
